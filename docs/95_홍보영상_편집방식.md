# 홍보영상 편집 방식 조사와 우리 영상 기준

1차 제출 영상(11/15 마감)을 만들기 위한 참고 문서. 같은 공모전 참가팀 영상 3편과 현대차·Pleos 공식 영상 3편을 내려받아 ffmpeg로 컷·전환·음량을 재고, faster-whisper로 대사를 받아 적어 분석했다 (2026-11-08).

- 컷 수: 장면 변화 기준값 0.3 (0이면 0.12로 다시 잼)
- 음량: EBU R128 통합 음량(LUFS)
- 글꼴 이름은 화면만 보고 추정한 값
- 장면 캡처: `docs/images/video-ref/` (파일 이름 = 영상_초)

참가팀 3편 모두 실제 Pleos 에뮬레이터에서 돌아가는 앱을 보여 주지 않는다. 우리는 실제 에뮬레이터 화면(진짜 기록 데이터, 3D 비행)을 그대로 보여 주고, 화면 아래에 "실제 Pleos 에뮬레이터 화면"을 작게 표시한다. 공감용 도입 2~3컷은 AI 생성 실사를 쓸 수 있다.

## 정리: 이기는 포인트
- 참가팀 3편은 모두 기능 나열이고 화면이 대부분 멈춰 있다. 차와 사람은 거의 나오지 않는다.
- 우리는 **한 사람의 하루 이야기** 안에 앱 화면을 넣는다. 기능은 "대사 한 줄 + 화면 한 컷"으로만 보여 준다.
- 편집은 Pleos 소개 영상처럼 **계속 움직이고**, 톤은 아반떼 광고처럼 **감정 한 줄**로 끝낸다.
- 안전 장면(운전 중 음성만, 회상은 정차 후)은 꼭 넣는다. 공식 영상과 로드스쿨 모두 강조하는 심사 포인트다.

## 우리 영상 편집 규칙

### 컷 속도
| 구간 | 장면 길이 |
|---|---|
| 도입 0~8초 | 2~3초 (밤 드라이브 2~3컷, 끝을 3D 지도로 이어 붙임) |
| 기록 8~35초 | 3~5초 |
| 기억 35~65초 | 5~8초, 3D 비행은 끊지 않음 |
| 공유 65~82초 | 1.5~2.5초 (뒤로 갈수록 빠르게) |
| 엔딩 82~90초 | 로고 + 한 줄 문구 4~5초 |

전체 25~30컷, 중간값 약 3초.

### 전환
- 기본은 하드컷. 막이 바뀔 때만 0.5~0.8초 크로스 디졸브.
- 기록 → 기억은 앱의 2D 지도를 확대하며 3D 지도로 잇는 매치컷.
- 회전 · 슬라이드 같은 효과 전환은 쓰지 않는다.

### 앱 화면
- 모든 앱 장면에 천천히 밀고 들어가는 확대(100% → 108%, 부드러운 가감속).
- 강조는 주변을 살짝 어둡게 하고 대상만 밝게 남긴다.
- 앱 화면은 연회색이나 남색 그라데이션 위에 살짝 기울여 띄우고 그림자를 준다. 실제 차 안 장면에서는 대시보드 화면 안에 넣는다. 3D 비행만 화면을 꽉 채운다.

### 글자
- 하단 자막: 한 줄 20자 이내, 흰색, 중간 굵기, 화면 높이의 4%.
- 왼쪽 위 작은 태그: `# 기록` `# 기억` `# 공유`.
- 큰 문구는 막마다 하나, 2초 이상.
- 나타날 때 0.3초 페이드 + 10px 위로.

### 색
- 밤 장면: 남색 · 주황 대비 (아반떼 톤).
- 앱 장면: 무채색 바탕 + 앱 강조색 하나.
- 엔딩 카드: 남색 바탕 + 흰 글씨.

### 소리
- 내레이션이 있으면 -16 LUFS, 순간 최대 -1 dBTP. 음악만이면 -14 LUFS.
- 음악은 내레이션보다 12~15dB 낮게, 말할 때 자동으로 줄어들게(덕킹).
- 처음 0.5초, 끝 1초는 음악 페이드.

### 시작과 끝
- 로고 애니메이션은 1초 이내로 짧게 하고 바로 장면으로 시작한다.
- 엔딩 카드: 로고 + 한 줄 문구 + 대회 해시태그.

## 도구별 구현 방법

| 기법 | DaVinci Resolve | ffmpeg |
|---|---|---|
| 천천히 확대 | Inspector Zoom · Position 키프레임, Dynamic Zoom | `zoompan=z='min(zoom+0.0005,1.08)':d=150` |
| 크로스 디졸브 | Cross Dissolve 0.5초 | `xfade=transition=fade:duration=0.5` |
| 3D로 기울여 띄우기 | Fusion Transform3D, 또는 DVE Perspective + Drop Shadow | `perspective` + `overlay` |
| 주변 어둡게 강조 | Power Window + Lift 낮추기 | `drawbox` + `boxblur` 합성 |
| 글자 페이드 · 올라오기 | Text+ Opacity · Y 키프레임 | `drawtext` `alpha=` 식 |
| 스피드 램프 | Retime Curve | `setpts` 구간 분할 |
| 색 맞추기 | Color 페이지 LUT, Shared Node | `lut3d` |
| 음악 자동 줄이기 | Fairlight Ducking | `sidechaincompress` |
| 음량 맞추기 | Deliver의 Normalize Audio Levels | `loudnorm=I=-16:TP=-1:LRA=7` |

자막은 Resolve로 넣는다. 이 PC의 ffmpeg `drawtext`는 글꼴 설정 문제로 멈춘다.
