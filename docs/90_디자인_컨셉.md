# 디자인 컨셉 — 길 위의 앨범

어디였지는 "차가 기억하는 나의 모든 길"이다. 화면은 **여행 앨범**처럼 보인다: 지나온 길은 점선으로 이어지고, 들른 곳은 사진으로 남고,
AI가 찾아 준 기억에는 금색 반짝임이 붙는다. Pleos 차량 화면 규칙(큰 글자 · 76dp 터치 · 높은 대비 · 운전 중 단순함)은 그대로 지킨다.

코드 위치: 색 `ui/theme/Color.kt`, 글자 `ui/theme/Type.kt`, 간격 · 모서리 `ui/theme/Theme.kt`, 무늬 · 그림 `ui/theme/EodiMotifs.kt`.

## 1. 색

라이트는 **종이 앨범**(따뜻한 종이색 바탕 + 흰 카드), 다크는 **밤길**(회색이 아닌 깊은 남색). 밤 운전 때 다크 화면이 눈부시지 않고, 파랑 브랜드와 한 가족으로 보인다.

| 역할 | 토큰 | 라이트 | 다크 | 쓰는 곳 |
|---|---|---|---|---|
| 바탕 | `background` | `#F5F2EC` 종이 | `#0A0F1A` 밤 | 창 바탕 |
| 카드 | `surface` | `#FFFFFF` | `#131B29` | 카드 · 목록 행 |
| 카드 안 칸 | `surfaceHigh` | `#F2EEE6` | `#1C2638` | 통계 칸 · 칩 · 아이콘 버튼 |
| 선 | `outline` | `#E3DDD2` | `#2C3850` | 구분선 · 점선 길 |
| 글자 1·2·3 | `textPrimary/Secondary/Tertiary` | `#151A24` · `#464D5C` · `#646B7A` | `#F2F4F8` · `#B9C2D0` · `#8F9AAD` | 제목 · 본문 · 보조 |
| **길 파랑** | `accent` = `trip` | `#0064FF` | `#3A87FF` | 주행 경로 · 주된 버튼 · 오늘 |
| **노을 코랄** | `stay` | `#E0522A` | `#F0643C` | 머문 곳 핀 · 정차 시간 · 일요일 |
| **반짝 금색** | `memory` / `memoryInk` | `#FFC233` / `#9A6200` | `#FFC94D` / `#FFC94D` | 기억 도장 "1년 전" · AI 반짝임 |
| 지금 초록 | `here` | `#008F4F` | `#2FD98C` | 지금 여기 |
| 하트 · 별 | `heart` · `star` | `#E5364F` · `#F5A800` | `#FF5C74` · `#FFC233` | 커뮤니티 |
| 남색 판 | `ink` / `onInk` | `#141B2B` / 흰색 | `#22304B` / 흰색 | 코스 안내 띠 · 사진 칸 바탕 |

- 지도 위 경로 · 핀 색(`MapInk`)은 바탕 지도가 라이트 하나라 라이트 값을 쓴다.
- 금색 면(`memory`) 위 글자는 `onMemory`(짙은 갈색), 바탕 위에 바로 쓰는 금색 글자 · 아이콘은 `memoryInk`.

### 대비 (WCAG AA)

본문 글자는 4.5:1 이상, 20sp 굵게 이상인 색 글자와 아이콘은 3:1 이상을 지킨다.

| 조합 | 라이트 | 다크 |
|---|---|---|
| 글자1 / 카드 | 17.4 | 15.7 |
| 글자2 / 카드 | 8.5 | 9.6 |
| 글자3 / 카드 · 바탕 | 5.4 · 4.8 | 6.1 · 6.8 |
| 파랑 글자 / 카드 | 4.9 | 5.0 |
| 흰 글자 / 파랑 버튼 | 4.9 | 3.5 (버튼 글자는 24sp 이상 굵게) |
| 코랄 글자 / 카드 | 3.9 (20sp 굵게 이상) | 5.4 |
| 흰 숫자 / 코랄 배지 | 3.9 | 3.2 |
| 금색 글자(memoryInk) / 카드 | 5.1 | 11.3 |
| 도장 글자 / 금색 | 8.9 | 10.7 |
| 흰 글자 / 남색 판 · 흐린 글자 / 남색 판 | 17.2 · 11.3 | 13.2 · 8.7 |

## 2. 글자

크기는 Pleos Font Hierarchy 그대로(팔 길이에서 1~2초 안에 읽힘), 가장 작은 글자는 20sp.

| 단계 | 크기/줄 | 굵기 | 쓰는 곳 |
|---|---|---|---|
| `hero` | 48/60 | Bold | 하루 상세 제목 |
| `title` | 34/44 | Bold | 머문 곳 이름 · 목록 날짜 |
| `titleSmall` | 32/40 | Bold, 고정폭 숫자 | 통계 값 · 날짜 타일 숫자 |
| `bodyStrong` · `body` | 28/36 · 26/34 | SemiBold · Normal | 주행 이름 · 본문 |
| `time` · `meta` | 28/34 · 24/30 | 고정폭 숫자 | 시각 · 거리 · 시간 |
| `label` | 24/28 | SemiBold | 버튼 · 칩 |
| `eyebrow` | 20/24 | Bold, 자간 +0.03em | 제목 위 머리말 · 기억 도장 |
| `caption` | 20/24 | Medium | 작은 표시 |

- 에이전트 화면의 보조 글자도 20sp(Pleos Label 최소)다.
- 시각 · 거리 · 시간 숫자는 고정폭(tnum) → 세로로 줄이 맞는다.

## 3. 모양

- 카드 모서리 28dp, 카드 안 칸 20dp, 사진 20dp(카드보다 한 단계 작게), 알약 · 칩은 완전히 둥글게.
- 그림자는 떠 있는 것(코스 안내 띠 · 말하기 카드 · 입구 버튼)에만. 목록 카드는 바탕색 차이로만 나눈다.
- 터치 76dp 이상, 주행 중 버튼 144dp.

## 4. 무늬 (조금씩만)

앱 아이콘의 세 요소를 화면에 나눠 쓴다. 한 화면에 한두 번까지만.

| 무늬 | 컴포넌트 | 자리 |
|---|---|---|
| 앱 표시 (파란 네모 · 점선 길 · 핀 · 금색 반짝임) | `BrandMark` | 왼쪽 레일 맨 위 |
| 점선 길 + 작은 핀 | `DottedRoute` | "날짜별 기록" 머리말 옆 |
| 기억 도장 (금색 알약 + 반짝임) | `MemoryStamp` | 에이전트 추천 카드 · 주행 중 기억 카드의 "1년 전" |
| AI 동그라미 (파랑 + 금색 반짝임) | `SparkleBadge` | 에이전트 답 앞 |
| 금색 반짝임 아이콘 | `EodiIcons.Sparkle` | 입구 버튼 · 질문 칸 · 예시 질문 |

그림(이미지 파일 없이 Compose로 그림, 테마 색을 따른다):
- `MemoryAlbumArt` — 에이전트 첫 화면: 점선 길 위에 앨범 사진 세 장(바다 · 노을 · 숲)이 살짝 기울어 놓이고 끝에 핀 + 반짝임.
- `EmptyRoadArt` — 기록이 없을 때: 지도 조각 위 길 → 코랄 핀 + 금색 반짝임.

## 5. 사진

- 들른 곳은 구글 Places 사진으로 보인다(`PlaceThumbnail` · `PlacePhotoGallery`). 사진이 없으면 코랄 옅은 칸 + 핀.
- 사진 위 글자는 `scrim` 받침 위에 흰 글자. 사진 칸 바탕은 남색 판(`ink`).
- 주행 중 기억 답에는 그날 첫 들른 곳 사진 한 장만 크게 둔다(`DrivingMemoryCard`).

## 6. 화면별 요점

- **레일:** 맨 위 앱 표시, 고른 탭은 옅은 파랑 칸 + 파랑 아이콘.
- **내 기록:** 날짜 타일은 달력처럼 토요일 파랑 · 일요일 코랄, 오늘은 파랑으로 채움. 하루 상세는 지도 + 시간선(주행 = 파랑 실선, 머문 곳 = 점선) + 사진.
- **검색:** 머리의 흰 알약 칸(돋보기 · 지우기 × · 옅은 파랑 마이크) + 옆 "✦ 물어보기"(마이크 없음, 마이크는 검색 칸 하나). 결과는 본문 자리를 대신하고 넓은 창은 두 칸. 줄 = 사진 · 제목 · 날짜 줄 + 지도(회색 동그라미) · 안내(파랑 동그라미). 질문 같은 말이면 맨 위 금색 테두리 "AI에게 물어보기" 카드.
- **에이전트(정차):** 첫 화면은 앨범 그림 + 반짝임 예시 질문. 답 카드는 "1년 전" 금색 도장이 맨 앞.
- **에이전트(주행):** 큰 카드 한 장. 처음은 옅은 고리 두 겹 안의 큰 마이크, 답은 질문 한 줄 · 사진 카드 한 장 · 답 글 · 큰 버튼 둘.
- **코스 안내 띠:** 라이트 · 다크 모두 남색 판 + 흰 글자 → 어느 화면 위에서도 "안내 중"으로 떠 보인다.
- **커뮤니티:** 하트 · 별 색은 토큰(`heart` · `star`), 코스 카드는 사진 줄이 주인공.

## 7. 움직임

- 짧고 싸게: 선택 색 바뀜 160ms, 좁은 창 목록 ↔ 상세 220ms 밀기 + 흐려짐, 코스 안내 띠는 펼치기 + 흐려짐.
- 반복 애니메이션은 "기다리는 중"에만(사진 자리 깜빡임, 생각 중 점 세 개, 말할 때 마이크 크기). 주행 화면의 고리는 움직이지 않는다.
- 지도 위 기호 층은 늘리지 않는다(지도 이동 성능).

## 8. 폰 판

- 같은 토큰 · 같은 부품을 쓰고 화면 전체를 **0.62배**로 그린다 (`phone/ui/PhoneUiKit.kt`의 `PhoneUiScale`). 차 글자는 팔 길이용이라 폰의 약 두 배다 →
  본문 26sp → 16sp, 가장 작은 글자 20 → 12.4sp, 하루 제목 48 → 30sp, 터치 76dp → 47dp. 시스템 글자 크기 설정은 그대로 따른다.
- 아래 탭 가운데는 AI 동그라미(`SparkleBadge`)가 막대 위로 살짝 뜬다. 운전 중에는 마이크로 바뀐다.
- 하루 상세: 위 약 40%가 지도(머문 곳 말풍선), 그 아래 통계 · 올리기 · 시간선이 한 목록.
- 물어보기: 대화처럼 위에 답 · 카드(세로로 쌓음), 맨 아래 엄지 자리에 질문 칸 + 큰 마이크.
- 시트(공유 · 리뷰 쓰기 · 설정 · 지도 앱 없음)는 아래에서 올라오고 위 모서리만 둥글다 + 손잡이.
- "운전 중 모드" 띠는 파랑 판 + 흰 마이크, 동승자 모드는 옅은 칸(`surfaceHigh`).

## 9. 지킬 것

- 색은 `EodiTheme.colors` 토큰으로 쓴다(고정색은 지도 그림 · 무늬 그림 안에만).
- 금색은 기억 · AI 전용. 버튼 · 선택 표시는 파랑.
- 코랄은 머문 곳 전용(핀 · 정차 시간 · 사진 없음 칸).
- 주행 화면은 사진 한 장 · 글 · 큰 버튼만으로 차분하게.
- 그림은 Compose로 그리고, 사진은 받아서 기기에 저장한 것을 쓴다(앱 안 이미지 파일은 아이콘뿐).
