> 기획서 **사업성** 항목(타깃 고객, 예상 MAU, Retention, 확대 계획)과 발표 자료를 쓸 때 참고하는 문서다.

## 한눈에

```
          무료 / 플러스(월 4,900원) · 업무 모드(회사가 차량 대수로)
   운전자 ─────────────────────────────▶ 어디였지 ◀──────────────── 제휴 매장 · 관광지
     ▲   자동 기록 · AI 기억 · 추천 코스        │   쿠폰 · "코스 공식 맛집" 노출      (음식점 · 카페 · 놀이공원 · 체험 · 휴게소)
     │                                        │
     └──── 쿠폰 들고 실제로 방문 ◀───────────────┘
           방문은 자동 기록 → 리뷰 → 커뮤니티 콘텐츠 → 다음 사람의 추천 코스
```

한 문장: **배달 앱이 음식을 집으로 가져온다면, 어디였지는 사람을 가게로 데려간다.**

## 1. 왜 오프라인인가 (발표 메시지)

- 배달·온라인 주문이 편해진 대신 "가 보고 싶은 가게"를 찾는 재미는 줄었다. 오프라인 매장·놀 거리에는 그곳에 가야만 얻는 경험이 있다.
- 오프라인 방문의 수단은 차다. **"다음에 어디 들르지?"를 정하는 순간이 차 안**이고, 그 순간에 추천하는 앱이 손님을 보낸다.
- 어디였지는 차가 **실제로 들른 곳을 자동으로 기록**한다 → "진짜 다녀온 사람"의 리뷰와 **실제 방문 순위**를 만든다. 조작 리뷰·광고 리뷰와 구별되는 신뢰가 우리 자산이다.
- 관광지 바깥의 로컬 가게, 온라인에 잘 안 보이는 **오프라인 전용 매장**도 방문 기록과 하트로 발굴된다 → 지역 상권과 지역사회가 같이 큰다 (지자체 협업 근거).

## 2. 수익원

### ① 구독 (B2C): 무료 · 플러스 월 4,900원

AI 기능이 고도화될수록 플러스의 가치가 커진다. LLM 호출 비용을 구독이 덮는 구조다.

| 기능 | 무료 | 플러스 (월 4,900원) |
|---|---|---|
| 자동 기록 · 타임라인 · 지도 · 정차한 곳 사진 | ✅ | ✅ |
| 기기 안 기억 검색 ("작년 여름 바다") | ✅ 기본 | ✅ |
| AI 기억 에이전트 대화 (자연어 질문 · 이어 묻기) | 하루 몇 번 | 무제한 |
| 근처 드라이브 추천 코스 (top-k · 대화로 고르기 · 바로 안내) | 기본 1개 | 상위 여러 개 · 취향 반영 |
| AI 하루 요약 · 센스 있는 제목 · 태그 | 최근 일부 | 전체 기간 |
| 회상 알림 ("1년 전 오늘", 그 길을 지날 때) | 기본 | 맞춤 · 횟수 조절 |
| 연말 결산 영상 · 코스 꾸미기 공유 | — | ✅ |
| 기록 보관 · 백업 | 1년 | 무제한 |
| 커뮤니티 · 여행 리뷰 · 쿠폰 받기 | ✅ | ✅ + 플러스 전용 쿠폰 |

- 무료로도 기록·회상의 핵심 가치를 준다 → 설치·이용자를 넓게 모으고, 쌓인 기록이 많아질수록 플러스로 넘어온다.
- 【확인】 Pleos 앱마켓의 인앱 결제·구독 지원 여부.

### ② 매장 · 놀 거리 제휴 (B2B): 할인 쿠폰과 노출

- **구조:** 제휴처가 할인 쿠폰을 등록한다 → 운전자의 코스 위에 있거나 근처를 지나면 "제휴 · 쿠폰"이 붙어 보인다 → 도착하면 쿠폰 카드를 띄우고 매장에서 보여 주고 쓴다.
- **손님을 몰아주는 방법:** 에이전트가 여행 코스를 짤 때 제휴처를 경로 위 경유지로 제안하고, 제휴처는 쿠폰을 더 주어 선택받는다. 코스 안에서 사람들이 그쪽으로 더 몰린다.
- **과금 방식 후보:**
  - 성과형: 쿠폰이 실제로 쓰이거나 방문이 기록되면 건당 수수료 (차 기록으로 **실제 방문을 확인**할 수 있는 게 강점)
  - 월 제휴비: "코스 공식 맛집" 배지 · 근처 노출
  - 시즌 패키지: 축제 · 단풍철 · 휴가철 코스에 묶어 노출
- **대상:** 음식점 · 카페, 놀이공원 · 테마파크, 체험 · 전시 · 공방, 휴게소 · 로컬 특산물 매장, 숙소, 전기차 충전소.
- **신뢰 원칙:** 인기순 · 추천 순위는 실제 방문과 하트 그대로 두고, 제휴는 "제휴 · 쿠폰" 표시로 구분해 보여 준다. 에이전트 답에도 제휴임을 말한다.

### ③ 지자체 · 관광공사 (B2G)

- 공식 테마 코스 ("가을 단풍 드라이브 10선", 지역 축제 코스)를 커뮤니티 드라이브 코스에 올린다.
- 지역 쿠폰(지역화폐 · 관광 쿠폰)과 묶어 관광객을 로컬 가게로 보낸다.
- 개인을 알 수 없게 묶은 방문 통계(어느 코스 · 어느 계절에 사람이 몰리는지)로 관광 정책을 돕는다.

### ④ 업무 모드: 회사원 · 출장 기록 (B2B 기업 구독)

여행만이 아니다. 차로 일하는 사람(영업 · 현장 점검 · 방문 서비스 · 출장이 잦은 회사원)도 시동만 걸면 똑같이 기록된다 → **출장 기록이 저절로 남는다.**

| 쓰임 | 어디였지가 해 주는 것 |
|---|---|
| 출장 기록 · 보고서 | 다녀온 거래처 · 현장 순서, 도착 · 출발 시각, 머문 시간이 그대로 남는다 → AI가 출장 보고서 초안을 쓴다 ("11/6 강릉 출장: 거래처 3곳, 총 384km") |
| 업무용 승용차 운행기록부 | 날짜 · 출발지 · 도착지 · 주행거리 · 업무용 여부를 기록에서 바로 뽑는다 (법인 업무용 승용차 비용 인정에 필요한 서류 【확인: 국세청 양식 · 기준 금액】) |
| 출장비 · 유류비 정산 | 업무 주행거리 × 회사 단가로 정산표 초안 |
| 방문 이력 | "지난달 ○○ 거래처 몇 번 갔지?"를 에이전트에게 묻는다 |

- **개인 · 업무 자동 구분:** 근무 시간, 회사가 등록한 거래처 · 현장, 출근길 · 퇴근길 에피소드(이미 규칙으로 구분됨)로 업무 주행을 골라낸다. 운전자가 한 번 눌러 고칠 수 있다.
- **개인정보:** 회사에는 업무로 표시된 주행만 넘어가고, 퇴근 뒤 · 주말 기록은 개인 기록으로 남는다.
- **과금:** 회사가 차량 대수 · 사용자 수 기준으로 낸다 (예: 차량 1대당 월 9,900원 【확인】). 회사가 비용을 내는 고객이라 혼자 써도 바로 가치가 있고, 법인 차량 단위로 한 번에 들어온다.
- **개인 사업자 · 프리랜서:** 차량 비용을 경비로 처리할 때 운행 기록을 쓴다 → 플러스 구독과 묶어 판다.

## 3. 사람이 가게로 가는 흐름 (데모 시나리오)

1. "여기 근처 드라이브 추천코스 안내해줘" → 에이전트가 하트 많은 코스 3개를 가져온다. 2번 코스의 카페에 "제휴 · 아메리카노 10%".
2. "2번으로 가자" → 차량 내비가 경유지를 넣어 안내한다.
3. 카페 도착 → 쿠폰 카드 → 방문이 자동으로 기록된다.
4. 정차한 곳 사진과 함께 "별점 남길까요?" → 리뷰가 여행 리뷰 탭의 새 콘텐츠가 된다.
5. 리뷰 · 하트가 쌓인 곳은 다음 사람의 추천 코스에 더 자주 나온다 (플라이휠).

## 3-1. 앱 안에서 보이는 모습 (시연)

> 지금 앱의 쿠폰은 **공모전 시연용 예시 데이터**다. 실제 매장과 맺은 제휴가 아니고, 시연 기록·커뮤니티에 나오는 이름난 장소에
> 그럴듯한 혜택을 붙여 코드에 넣어 둔 값이다 (`core-rs/src/offers.rs`). 2차 단계에서 서버가 제휴처 쿠폰을 내려 주면 그 목록으로 바뀐다.

- **배지:** 제휴처가 있는 곳에 귤색 티켓 배지가 붙는다 — 검색 결과 장소 · 리뷰 줄, 하루 상세의 머문 곳, 내 장소 카드("10% 할인", "리터당 100원 할인"),
  커뮤니티 드라이브 코스 · 에이전트 추천 코스 카드("쿠폰 2곳"), 여행 리뷰 카드.
- **쿠폰 창:** 배지를 누르면 제휴처 · 혜택 · 조건 · 기한과 "쿠폰 받기". 받으면 "받았어요"와 쿠폰 번호(예: EODI-7K3Q)가 보이고, 매장에서 그 번호를 보여 준다.
- **쿠폰함:** 내 장소 › 쿠폰함에 받은 쿠폰이 모인다.
- **에이전트:** 정차 중 추천 코스 답에 한마디 — "이 코스엔 제휴 쿠폰이 2곳 있어요." 주행 중 답은 그대로 짧게 두고, 쿠폰 창도 띄우지 않는다.
- **어느 곳에 붙나:** 장소 이름(띄어쓰기 무시)으로 맞추고, 카카오 이름이 조금 달라도 300m 안이고 이름이 겹치면 같은 곳으로 본다. 계산은 Rust가 한다.
- **시연 예:** 강릉 초당할머니순두부 "10% 할인", 테라로사 "원두 10% 할인", 안목해변 카페 "아메리카노 1+1", 대관령 양떼목장 "입장료 20% 할인",
  SK에너지 응봉주유소 "리터당 100원 할인", 이마트 성수점 "5,000원 할인" 등 16곳.

## 4. 숫자 틀 (가정)

| 항목 | 가정 | 계산 |
|---|---|---|
| 예상 MAU | 탑재 차량 100만 대 × 설치 5% × 월 사용 50% (`docs/00_plan.md`) | 약 2.5만 |
| 플러스 전환 | MAU의 3~5% 【확인】 | 750~1,250명 × 4,900원 = **월 약 370만~610만 원** |
| 매장 제휴 | 시범 지역(강원) 100곳 × 월 3만 원 【확인】 | 월 약 300만 원 |
| 성과 수수료 | 쿠폰 사용 월 5,000건 × 건당 300원 【확인】 | 월 약 150만 원 |
| 업무 모드 | 법인 차량 1,000대 × 월 9,900원 【확인】 | 월 약 990만 원 |

비용 쪽에서 볼 것: LLM 호출(서버), 장소 사진(구글 Places: 월 무료 한도 넘으면 사진 1,000건당 약 7달러), 지도 데이터, 서버 운영. 사진·장소 결과는 기기에 저장해 다시 부르지 않아서 사용자가 늘어도 호출이 덜 는다.

탑재 차량이 늘수록(현대차그룹 2030년 2,000만 대 계획) 같은 비율로 커진다.

## 5. Retention (계속 쓰는 이유)

- 시동만 걸면 기록된다 → 다시 열 이유를 따로 만들 필요가 없다.
- 기록이 쌓일수록 회상 · AI 검색 · 연말 결산의 가치가 커진다 → 오래 쓸수록 떠나기 어렵다.
- 쿠폰 · 리뷰 · 하트 · 커뮤니티 질문 답이 주말마다 다시 열 이유가 된다.

## 6. 앱에서 바로 보여 줄 수 있는 근거

| 사업성 주장 | 지금 앱의 기능 |
|---|---|
| 실제 방문 기반 신뢰 | 자동 기록된 경유지 · 정차 시간 · 정차한 곳 사진 |
| 사람을 가게로 보낸다 | 에이전트 근처 추천 코스 → 내비 경유지 안내 |
| 제휴 쿠폰 노출 (시연용 예시) | 장소 · 코스 · 리뷰 카드의 쿠폰 배지 → 쿠폰 받기 → 내 장소 › 쿠폰함, 추천 코스 답의 "제휴 쿠폰 2곳" |
| 출장 기록이 저절로 남는다 | 출근길 · 퇴근길 · 볼일 · 여행 자동 구분, 하루 상세의 경유지 · 정차 시간 · 거리 |
| 콘텐츠가 저절로 쌓인다 | 내 기록 한 번에 커뮤니티 공유, 들른 곳 리뷰, 하트 인기순 |
| 지역 발굴 | 여행 리뷰 탭 인기 장소 순위 (계절 · 날씨와 함께) |
