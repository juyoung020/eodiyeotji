# 시연 영상 · 표지 GIF 자동 녹화

에뮬레이터에서 실제로 앱을 움직여 시연 영상(`demo.mp4`)과 README 표지 GIF(`cover.gif`)를 한 번에 찍는다.
손으로 누르지 않고 `scripts/demo/record-demo.ps1`이 화면 글자를 찾아 누르고, 차 상태(기어 · 속도 · 위치)를 바꾸고, 녹화 · 편집까지 한다.

## 실행

두 에뮬레이터(차 `emulator-5554`, 폰 `emulator-5556`)를 켜 둔 뒤 저장소 루트에서:

| 목적 | 명령 | TTS |
|---|---|---|
| 리허설 (언제든, 무료) | `powershell -ExecutionPolicy Bypass -File scripts\demo\record-demo.ps1` | 기기 안 엔진 (평소 빌드) |
| 최종본 (제출 직전 한 번) | `powershell -ExecutionPolicy Bypass -File scripts\demo\record-demo.ps1 -Final -CaptureAudio` | 서버 고음질 (`-PPREMIUM_TTS=true` 빌드, 유료) |

- 결과는 `build\demo\<날짜-시각>\` (git에 안 올라감): `demo.mp4`(1920×1080, 장면마다 아래 자막, 약 3분 · 15MB) · `cover.gif`(800×450, 약 10초 반복 · 1.5MB) · `scenes\*.mp4`(장면 원본).
- 한 번에 약 12분: 빌드 → 차 앱 지우고 새로 설치(디버그로 오프라인 지도 넣고 릴리즈를 덮어 설치) → 폰 앱 새로 설치 → 장면 7개 녹화 → 편집.
- 일부만 다시: `-Scenes convoy,biz -SkipBuild -SkipInstall -Out <이전 폴더>` 뒤 `-EditOnly -Out <이전 폴더>`로 편집만.
- README 표지를 바꿀 때는 `cover.gif`를 새 이름(`docs/images/demo-YYYY-MM-DD.gif`)으로 넣는다 (GitHub 캐시 때문).

## 장면 (스토리보드)

| # | 장면 | 화면 | 하는 일 |
|---|---|---|---|
| 0 | 제목 | 어디였지 · 차가 대신 기억합니다 | |
| 1 | 첫 실행 | 차 | 빈 화면 → "시연 기록 넣기" → 1년치 기록 · 커뮤니티 |
| 2 | 기억 찾기 | 차 | 검색 칸에 화면 키보드로 "바다 어디였지" → 기기 안 결과 즉시 → AI에게 물어보기 → 경포해변 카드 · 코스 |
| 3 | 그날로 돌아가기 | 차 | 1년 전 오늘 강릉 여행을 3D로 다시 달리기 |
| 4 | 코스 안내 | 차 → 내비 | "이 코스로 안내" → 경유지 2개씩 구간 나눈 내비 경로 |
| 5 | 같이 가기 | 차 (정차 → 주행) | 경포해변 장소 창 → 같이 가기 → 새로 만들기 → 시연 차 2대 자동 참여 · 민수 배터리 부족 → 기어 D로 영동고속도로 주행(`scripts/demo/routes`) → 지현이 4km 넘게 뒤처짐 → "횡성휴게소에서 기다릴까요?" 음성 + 큰 버튼 → 누르면 내비 경유지. 주행 대기 구간은 빨리 감기 |
| 6 | 출장 관리 | 차 | 모아보기 → 출장 관리 → 출장 하나 |
| 7 | 폰 앱 | 폰 | 시연 기록 넣기 → 내 기록 → 커뮤니티 |
| 8 | 끝 | 달린 길은 잊혀도, 차는 기억합니다 | |

표지 GIF는 2(AI 답) → 3(3D 다시 달리기) → 5(휴게소 제안)의 짧은 조각을 이어 붙인다.

## 소리

- `adb screenrecord`에는 소리가 없다. `-CaptureAudio`를 주면 PC 기본 스피커로 나오는 소리를 장면마다 WAV로 받아 영상에 넣는다 (`scripts/demo/loopback-rec.py`, `pip install --user soundcard`).
  에뮬레이터 소리가 PC 기본 출력 장치로 나와야 하고, PC의 다른 소리도 같이 들어간다. 녹음 시작 시점이 1초 안쪽으로 어긋날 수 있다.
- 내레이션 · 배경 음악은 편집(홍보 영상 소스 `Desktop\eodiyeotji-promo`)에서 넣는다. 편집 기준은 `docs/95_홍보영상_편집방식.md`.

## 알아 둘 것

- 한글은 `adb input text`로 못 넣어서 차 화면 키보드(두벌식, 2560×1440)의 자모 칸을 좌표로 누른다 (`demo-lib.ps1`의 `Type-CarHangul`). 키보드 배치가 바뀌면 좌표를 고친다.
- 그 밖의 버튼은 `uiautomator dump`로 글자를 찾아 누른다 (한 번에 약 2초). 화면 문구가 바뀌면 `record-demo.ps1`의 글자 패턴을 고친다.
- 처음 실행 장면은 데이터를 지운 새 설치에서만 맞다 (`-SkipInstall`이면 "시연 기록 넣기" 버튼이 없다).
- 같이 가기 장면의 AI 답(경포해변 / 해운대)과 휴게소 제안 시각은 실행마다 조금 다르다. 스크립트가 시각을 재서(`marks.json`) 자르므로 따로 고칠 것은 없다.
- 녹화가 끝나면 차는 기어 P · 속도 0, 릴리즈 판이 깔린 상태로 남는다.
