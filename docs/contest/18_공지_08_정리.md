# 공지 정리: 공모전 개발 범위 및 기술 문의 안내

## 1. 공개된 SDK · API 범위에서 개발한다

- Pleos Playground 개발 문서에 공개된 SDK · API만 쓴다. 문서에 없는 기능이 필요하면 **기획서에 향후 계획으로** 적는다.
- 쓸 수 있는 SDK: Vehicle, NaviHelper, TextToSpeech, SpeechToText, FusedLocation. 워크스페이스에 '준비 중'으로 보여도 문서대로 에뮬레이터에서 개발 · 시험할 수 있다.
- 문서에 없는 SDK와 **Pleos LLM SDK는 제공되지 않는다** → 어디였지는 LLM을 외부 API로 쓴다 (설명회에서 외부 API · 인터넷 허용).
- 참가팀은 Gleo Interface(App Schema) 검토 · 승인을 신청할 수 없다.
- **차량 마이크 음성을 외부 음성 인식 서비스로 보내면 안 된다. 음성 인식은 SpeechToText SDK로 한다.**
  - 어디였지 차량 판은 Pleos SpeechToText SDK로 받아 쓴다 (`app/src/car/.../pleos/PleosSpeech.kt`). 외부로 가는 것은 받아 쓴 글자뿐이다.

## 2. 심사는 기획서와 에뮬레이터 시연으로 한다

- 1차는 접수양식(기획서)만으로도 지원할 수 있다. 시연 영상 · GitHub · APK는 선택(가산점).
- 2차 PT는 Pleos Connect 에뮬레이터에서 앱을 돌려 시연한다. 실제 차량은 필요 없다.
- 이 심사는 Pleos App Market 입점 심사가 아니다 (입점 정책은 Playground 안내를 따른다).

## 3. 기술 문의

- 공모전 안내는 참가 가이드, 기술 세부는 Pleos Playground 개발 문서에서 본다.
- 운영사무국은 참가 자격 · 접수 · 제출 · 일정 문의에만 답한다. 구현 방법 · API 동작 문의에는 답하지 않는다.
- 장비 대여 · 실차 측정 장소 · 별도 기술 지원 창구는 없다.
