# 공지 정리: 비공개 GitHub 저장소 제출 방법 및 접수 관련 추가 안내

이 공지로 "심사용 계정을 Collaborator로 초대" 안내가 바뀌었다. 사이트의 지원·제출 방법 · FAQ 페이지도 같은 내용으로 바뀌어 `05_제출방법_양식.md` · `10_FAQ.md`에 반영했다 (11/12).

## 1. 비공개 저장소 제출 — 방법이 바뀌었다

- 심사용 계정을 Collaborator로 초대하지 않아도 된다. 이미 초대했어도 아래 방법으로 낸다.
- 접수 마감(11/15 23:59)까지는 비공개로 둬도 된다. 대신 접수 메일에 **저장소 주소와 최종 커밋 번호(commit hash)** 를 적는다.
- 마감 뒤 **11/16(월)까지 공개(Public)로 바꾸고, 1차 결과 발표일(11/23)까지 공개 상태를 유지**한다.
- 심사는 11/16부터 메일에 적힌 최종 커밋을 기준으로 한다. 그래서 공개로 바꾸지 않으면 **개발 산출물 가산점이 반영되지 않는다.**
- 공개가 어려우면, 소스와 APK를 압축한 파일의 내려받기 주소를 마감 전에 접수 메일로 보내도 된다.
- 이미 접수했다면 접수한 메일 주소로 최종 커밋 번호만 회신한다.

## 2. 접수양식 · 서명

- 전자서명(패드 · 마우스)과 서명 이미지 삽입을 모두 인정한다. DOCX와 PDF 모두 낼 수 있다.
- 필수 항목과 순서를 지키면 글꼴 · 표를 바꾸거나 이미지 · 도표를 넣어도 된다.
- 대표자가 아닌 팀원 메일로 내도 된다. 다만 수정 제출은 처음 낸 메일 주소로 보낸다.

## 3. 추가 자료

- PPT, PDF, HTML 같은 추가 자료를 첨부해도 된다 (심사 참고용).
- 시연 영상과 첨부 자료는 분량 제한이 없다.

## 4. 심사 환경

- 심사에 실제 차량은 필요 없다. **개발에 쓴 Pleos Connect 에뮬레이터 버전과 화면 규격을 README에 적는다.**
- API 키 같은 비밀값은 저장소에서 빼도 된다. 자체 서버 소스는 필수가 아니다.

## 5. 2차 PT

- 일정, 참석 방식, 장비 · 인터넷은 본선 진출팀에 따로 안내한다.
