안내

비공개 GitHub 저장소 제출 방법 및 접수 관련 추가 안내

안녕하세요 공모전 운영사무국입니다.

참가자 여러분의 문의가 많았던 사항을 안내드립니다.

1. 비공개 GitHub 저장소 제출 방법

  • 심사용 계정을 Collaborator로 초대하실 필요는 없습니다. 이미 운영사무국 메일 주소를 초대하신 경우에도 아래 방법으로 제출해 주시면 됩니다
  • 접수 마감(11월 15일 23:59)까지는 저장소를 비공개로 두셔도 됩니다. 접수 메일에 저장소 주소와 최종 커밋 번호(commit hash)를 적어 제출해 주세요
  • 접수 마감 후 11월 16일(월)까지 저장소를 공개(Public)로 전환하고, 1차 심사 결과 발표일(11월 23일)까지 공개 상태를 유지해 주세요
  • 심사는 11월 16일부터 접수 메일에 적힌 최종 커밋 기준으로 진행합니다. 공개로 전환되지 않으면 개발 산출물 가산점이 반영되지 않습니다
  • 저장소 공개가 어려운 경우에는 소스 코드와 APK를 압축한 파일의 내려받기 주소를 접수 마감 전까지 접수 메일로 보내 주셔도 됩니다
  • 이미 접수를 마치신 경우에는 접수하신 메일 주소로 최종 커밋 번호만 회신해 주시면 됩니다

2. 접수양식 및 서명

  • 전자서명(패드·마우스 서명)과 서명 이미지 삽입을 모두 인정합니다. DOCX와 PDF 모두 제출하실 수 있습니다
  • 필수 항목과 순서를 지키면 글꼴·표를 바꾸거나 이미지·도표를 넣으셔도 됩니다
  • 대표자가 아닌 팀원의 메일로 제출하셔도 됩니다. 다만 수정 제출은 처음 제출한 메일 주소로 보내 주세요

3. 추가 자료

  • PPT, PDF, HTML 등 추가 자료를 함께 첨부하셔도 됩니다. 필수 제출 자료가 기본이며, 추가 자료는 심사 참고용입니다
  • 시연 영상과 첨부 자료의 분량에는 별도 제한이 없습니다

4. 심사 환경

  • 심사에 실제 차량은 필요하지 않습니다. 개발에 사용한 Pleos Connect 에뮬레이터 버전과 화면 규격을 README에 적어 주세요
  • API 키 등 비밀값은 저장소에서 빼셔도 됩니다. 자체 서버 소스 제출은 필수가 아닙니다

5. 2차 PT

  • 2차 PT의 일정, 참석 방식, 장비·인터넷 등은 본선 진출팀에게 별도로 안내드립니다
