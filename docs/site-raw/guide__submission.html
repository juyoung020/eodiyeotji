지원·제출 방법

제출물을 준비한 후, 아래 안내에 따라 이메일로 접수해 주세요.

이메일 지원 절차

  1. 01 · 양식과 제출물 준비

    공모전 접수양식 · 개인정보 수집·이용 동의서 다운로드 (DOCX)

    • 접수양식이 곧 기획서입니다. 작성한 접수양식을 준비해 주세요.
    • 시연 영상, GitHub 저장소, APK는 선택 제출이며 제출 수준에 따라 가산점이 부여됩니다.
    • 숏폼 챌린지 링크 제출은 선택 사항입니다.

    *숏폼 챌린지는 공모전 본상과 별도로 운영되는 특별상으로, 참여팀 중 우수한 숏폼 콘텐츠를 제작한 1팀을 선정하여 상금 50만원을 수여하고 현대자동차그룹 공식 행사에 초청합니다.

  2. 02 · 참가자 전원 개별 동의

    개인 참가자 또는 대표자와 팀원 전원(대표자 포함 최대 5인)이 각각 동의 여부, 서명과 날짜를 작성합니다. 대표자는 팀원 전원을 참조수신(CC)하여 제출해 주세요.

  3. 03 · 이메일 제출

    접수 기간은 2026.10.21–2026.11.15까지입니다. 작성·서명한 접수양식(기획서)과 선택 제출물을 아래 주소로 보내 주세요.

접수 이메일

appdevchallenge@hyundai-partners.com

메일 제목
[차량용 앱 개발 공모전] 팀명(개인은 성명)_대표자명

수정 제출

제출한 내용을 수정하려면 마감 전까지 처음 제출한 이메일 주소로 수정된 자료를 다시 보내주세요.
여러 번 제출한 경우, 마감 전 마지막으로 제출한 자료를 최종본으로 심사합니다.

이메일 제목: [수정제출] [차량용 앱 개발 공모전] 팀명(개인은 성명)_대표자명

수정 제출 시에도 전체 제출 자료와 서명한 동의서를 모두 첨부하고, 팀원 전원을 참조(CC)해 주세요.

제출물

01접수양식(기획서)필수

접수양식에 아이디어와 기획내용 작성

02시연 영상선택

목업 · 프로토타입 · 화면 녹화 인정

03GitHub 저장소선택

소스 코드 및 APK 포함

04숏폼 링크선택

접수양식(기획서)에 기재 · 가산점 없음

  • 1차 접수 시 시연 영상, GitHub 저장소, APK 등을 함께 제출하면 단계별 가산점을 부여합니다.
  • 2차 PT 심사 대상 팀은 PT 심사 전까지 실제 동작 가능한 앱 개발을 완료해야 합니다.
  • 1차 접수 시 제출했던 개발 산출물은 2차 PT 심사 전까지 자유롭게 추가 디벨롭(고도화)이 가능합니다.

GitHub 저장소 제출 안내

GitHub 저장소에 소스 코드와 APK 파일을 함께 업로드해 제출해 주세요.

제출 방법

  1. 새 GitHub 저장소를 만들거나 기존 개발 저장소를 사용합니다.
  2. 프로젝트 소스 코드를 저장소에 업로드합니다.
  3. APK 파일은 저장소 내 apk/ 폴더에 업로드합니다.
  4. 저장소 주소와 APK 파일 경로를 제출 페이지에 입력합니다.

APK 파일명

팀명_앱이름_release.apk

제출 전 확인해 주세요

  • APK는 실행 가능한 release 버전으로 제출해 주세요.
  • APK 파일이 GitHub 업로드 용량을 초과하는 경우, GitHub Releases에 등록한 후 해당 Release 페이지 주소를 제출해 주세요.
  • 비공개(Private) 저장소도 제출할 수 있습니다. 비공개 저장소를 제출하는 경우, 공지된 심사용 GitHub 계정을 Collaborator로 초대해 주세요.
  • 비공개 저장소는 제출 마감 전 심사용 계정에서 정상적으로 접근할 수 있는지 반드시 확인해 주세요.
  • 개인 계정의 비공개 저장소는 Collaborator에게 읽기뿐 아니라 쓰기 권한도 부여되므로, 초대 전 저장소 권한을 확인해 주세요.
  • README.md에는 아래 내용을 작성해 주세요.
    • 앱 이름 및 한 줄 소개
    • 실행 방법
    • 테스트 환경 및 필요한 설정
    • APK 파일 위치 또는 GitHub Release 링크

개인정보 동의와 출품작 권리

개인 참가자 또는 대표자와 팀원 전원은 다운로드 양식에 각각 동의·서명·날짜를 작성합니다. 수집 항목은 성명, 소속(선택), 휴대폰번호, 이메일 주소, 팀원정보(팀 참가 시), 서명입니다.

공모전 및 현대자동차그룹 연계 행사 종료 및 후속일정(2027년 2월 28일)까지 보관 후 지체 없이 파기하며, 수상자에 한해서만 결과 발표일로부터 2년까지 보유 후 파기합니다.
