# 같이 가기 (여러 차가 함께) — 만든 것과 시연법

## 무엇을 하나
여러 차가 같은 목적지로 갈 때 6자리 숫자 코드로 모여 목적지와 서로의 실시간 위치를 나눈다.

- **정차 중**: 머리의 "같이 가기" 칩, 또는 장소 창의 "같이 가기"(그곳이 목적지가 된다) → 새로 만들기 / 코드로 참여.
  창 왼쪽에는 지도(나 = 파랑, 다른 차 = 산호 · 보라 · 청록 · 분홍 점 + 이름 첫 글자 + "민수 · 1.2km 뒤", 목적지 핀, 지나온 길),
  오른쪽에는 코드 · 차 목록 · [목적지로 함께 안내](NaviHelper) · [코드 보내기] · [나가기].
- **주행 중**: 큰 카드 1장("민수 차 · 2.1km 뒤 · 도착 5분 차이")만 보인다. 목록과 창은 숨긴다.
  음성은 누가 도착함 · 누가 3km 넘게 뒤처짐만, 60초 간격 · 한 번에 12번까지 (SpeechOutput이 내비 음성과 오디오 포커스를 지킨다).
- **개인정보**: 켠 동안만 4초마다 위치를 보낸다. 나가기 · 내가 목적지 도착 · 12시간이면 끝. 서버는 메모리에만 두고 10분 소식 없는 차는 지운다.
  켜져 있으면 머리에 "위치 공유 중 · N대".

## 구조
| 곳 | 맡는 일 |
|---|---|
| `server/relay/src/convoy.js` | `POST /convoy`(만들기) · `POST /convoy/join` · `POST /convoy/:id/pos` · `POST /convoy/:id/dest` · `POST /convoy/:id/leave` · `GET /convoy/:id?member=`. Durable Object `ConvoyHub` 하나의 메모리 (wrangler.toml에 추가). 인증은 기존 `APP_TOKEN`(X-Eodi-App). 테스트 `npm test` |
| `core-rs/src/convoy.rs` | 목적지까지 거리 · 나와의 간격(앞/뒤) · 도착 시각 차이 · 끊김(60초) · 도착(150m) · 알림 문구와 횟수 제한 · 지도 GeoJSON. `ffi.rs`의 `ConvoyTracker` |
| `app/.../convoy/` | `ConvoyRepository`(보내기 · 받기 루프, IO 3초 타임아웃, 끊기면 마지막 상태 유지), `ConvoyBackend`(중계 / 기기 안 시연) |
| `app/.../ui/convoy/` | 칩 · 창 · 주행 카드 · 지도 (MapLibre, Rust GeoJSON 그대로) |

## 시연 (에뮬레이터 한 대)
**중계 서버를 쓸 때** (먼저 `cd server/relay; npx wrangler deploy` — Durable Object가 새로 생긴다):
1. 앱에서 장소 창 → "같이 가기" → 새로 만들기. 코드 6자리가 보인다.
2. `powershell -ExecutionPolicy Bypass -File scripts\convoy-fake.ps1 -Code <코드>` → 민수(2.5km 뒤) · 지현(0.8km 앞)이 목적지로 달린다.
3. `scripts\replay.ps1`로 내 차를 달리게 하면(기어 D) 주행 카드로 바뀐다.

**중계 서버 없이** (`RELAY_URL` 없이 빌드한 디버그 판, 창에 "이 기기 안 시연 모드"):
1. 같이 가기 → 새로 만들기
2. `powershell -ExecutionPolicy Bypass -File scripts\convoy-fake.ps1 -Local` (또는
   `adb shell am broadcast -a app.eodiyeotji.DEBUG_CONVOY --es name 민수 --ef behind_km 2.5 --ef speed_kmh 50`)

## 남은 것 · 정할 것
- 폰 판 화면(`app/src/phone`)에는 아직 입구가 없다 (공통 `HomeRoute`를 쓰는 차 판만). 장소 창의 "같이 가기"는 두 판 모두에 있다.
- ETA는 내비 값을 아직 안 넘긴다 → Rust가 남은 거리 ÷ 시속 40km로 어림한다. 간격은 직선 기준 "목적지까지 남은 거리" 차이.
- 받기는 4초 폴링 (SSE는 넣지 않았다).
