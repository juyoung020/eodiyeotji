# 소통

팀원끼리 보고하고, 묻고, 같이 정할 것을 남기는 곳이다. GitHub 이슈는 **버그·문의용**이라 그 밖의 이야기는 여기에 쓴다.

## 쓰는 법

- 한 주제 = 파일 하나. 이름은 `YYYY-MM-DD_이름_제목.md` (예: `2026-11-06_권혁신_다른PC세팅확인.md`)
- 맨 위에 상태를 적는다: `열림` (답·결정 기다림) / `정리됨` (결론 남, 문서 반영 끝)
- 받는 사람을 적는다 (`@김주영`, `@권혁신`, `@모두`)
- 답은 같은 파일 아래 `## 답 — 이름 (날짜)`로 이어 쓴다. 새 파일을 만들지 않는다.
- 결론이 나면 해당 문서(백로그 `docs/00_plan.md`, 세팅 문서, README 등)에 반영하고 상태를 `정리됨`으로 바꾼다.
- 쓰고 나면 커밋·푸시하고, 카톡으로 "소통 폴더에 올렸어" 한 줄만 보낸다.
