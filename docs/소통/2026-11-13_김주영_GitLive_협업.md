# GitLive로 겹치지 않게 같이 일하기 (2026-11-13, 김주영)

마감 전에 여러 명(+AI 도구)이 같은 시간에 고치다 보니 같은 파일이 겹쳤다 (예: 출장 관리 `BizScreen.kt`).
Git은 푸시하기 전 수정을 보여 주지 않으므로, **커밋 전 수정까지 실시간으로 보여 주는 GitLive**를 모두 쓴다.

## 설치 (각자 한 번, 5분)
1. VS Code로 저장소를 열면 오른쪽 아래에 "권장 확장 설치" 알림이 뜬다 → 설치. (안 뜨면 확장 탭에서 `GitLive` 검색, ID `TeamHub.teamhub`)
2. 왼쪽 GitLive 아이콘 → **GitHub로 로그인** → `eodiyeotji` 저장소 연결.
3. GitLive 패널에 팀원이 보이면 끝.

## 쓰는 법
- 편집기 왼쪽 여백 표시: 팀원이 지금 고치고 있는 줄. 마우스를 올리면 차이 · 브랜치가 보인다.
- **빨간 표시 = 내 수정과 겹침.** 그 부분은 먼저 고치는 사람과 말을 맞춘다.
- 작업 시작 전에 GitLive 패널에서 누가 어떤 파일을 고치는지 보고 피한다.

## 그래도 지킬 것
- 작업 전 `git pull`, 큰 작업이 끝나면 바로 커밋 · 푸시 (CLAUDE.md Git 규칙).
- `CHANGELOG.md` · `Color.kt` · `ffi.rs` · `strings_*.xml`처럼 모두 한 줄씩 넣는 파일은 맨 끝에 추가하고 바로 푸시한다.
- 비밀값(`local.properties`)은 git에서 빠져 있어 GitLive로도 공유되지 않는다.
