# 에이전트가 먼저 말 걸기 · 여러 단계 대화 — 시연 방법

작성: 2026-11-13 · 코드: `core-rs/src/proactive.rs`(고르기 · 문장 · 횟수), `app/src/main/java/app/eodiyeotji/agent/ProactiveCenter.kt`(차 상태 모으기 · 실행), `ui/agent/ProactiveCard.kt`(카드)

## 무엇을 하나
| 계기 | 언제 | 말 | "응"이면 |
|---|---|---|---|
| 출발 | 시동 / 기어 P→D (주행 시작 4초 뒤, 내비 목적지가 없을 때) | "수요일이네요. 늘 가던 현대자동차 남양연구소로 안내할까요?" (같은 요일 · 이 시간쯤 2번 이상 간 곳, 또는 오늘이 "늘 가던 날"인 곳) | NaviHelper로 안내 (안내 중 카드) |
| 잔량 부족 | 주행 중 3분마다 · 내비 목적지가 바뀔 때 | "강릉까지 배터리가 부족해요. 예전에 들렀던 ○○ 충전소를 경유지로 넣을까요?" (전기차는 충전소, 내연기관은 주유소, 돌아가는 거리 30km 이하) | 그곳을 경유지로 넣어 다시 안내 (경유지 2개가 이미 차 있으면 묻지 않음) |
| 도착 | 내비 도착(onDestinationArrived) 또는 주행 뒤 기어 P | 온 적 있는 곳이면 "1년 전 오늘도 여기 왔었어요." / "지난번엔 8월 1일에 왔었어요." (알려 주기만) — 처음 온 곳이고 출장 규칙에 맞으면 "○○에 다녀온 길, 출장으로 기록할까요?" | 그날을 출장으로 표시 (`set_biz_mark`) |

- 카드 한 장 + 짧은 음성 → 바로 마이크가 6초 듣는다 ("응/네/좋아" · "아니/괜찮아/나중에"). 못 알아들으면 카드의 [예] [아니요]를 기다린다.
- 하루 4번, 아무 제안 사이 2분, 출발 6시간 · 잔량 30분 · 도착 10분 쉼. "아니"라고 한 출발 · 잔량 제안은 그날 다시 묻지 않는다. 내비 안내 음성이 나오는 중이면 묻지 않는다.

## 여러 단계 대화 (2차 PT)
에이전트 화면(정차 중)에서 차례로 말한다 (에뮬레이터는 `DEBUG_VOICE` 브로드캐스트로 말 넣기).
1. "주말에 바다 가자" → Rust가 알아듣고 "바다 보러 가기 좋은 드라이브 코스" 추천으로 바꿔 묻는다 → 코스 카드 + 안내 제안
2. "같이 갈 사람 초대해줘" → 그 코스 끝점을 목적지로 같이 가기 모임을 만들고 참여 코드를 말해 준다 (`ConvoyRepository.create`, 중계 서버가 없으면 기기 안 시연 모임)
3. "출발하자" / "안내해줘" → 그 코스로 안내 시작 (구간 나누기 · 도착하면 다음 구간은 기존 `course::split_legs` · `CourseGuide`)

```powershell
adb shell am broadcast --user 10 -a app.eodiyeotji.DEBUG_VOICE --es text "주말에 바다 가자"
```

## 에뮬레이터에서 시연
디버그 판(`./gradlew installCarDebug`)에 있는 수신기로 계기를 바로 일으킨다. 오늘 횟수 기록은 매번 지운다 (`--ez reset false`로 끔).
```powershell
# 1) 출발 — 실제처럼 하려면 기어 P→D (시동 항목이 없어 기어로 대신)
powershell -ExecutionPolicy Bypass -File scripts\vc.ps1 -Gear Drive -Speed 40
#    또는 바로
adb shell am broadcast --user 10 -n app.eodiyeotji/.agent.ProactiveDebugReceiver --es event departure

# 2) 잔량 부족 — 에뮬레이터는 잔량을 바꿀 수 없어 값을 넣는다 (시연 기록에는 주유소만 있어 --ez ev false)
adb shell am broadcast --user 10 -n app.eodiyeotji/.agent.ProactiveDebugReceiver --es event lowbattery --es range_km 40 --es dest_name 경포해변 --es dest_lat 37.8055 --es dest_lon 128.9081 --ez ev false

# 3) 도착 — 기어 P (주행 끝) 또는 위치를 넣어 바로
powershell -ExecutionPolicy Bypass -File scripts\vc.ps1 -Speed 0 -Gear Park
adb shell am broadcast --user 10 -n app.eodiyeotji/.agent.ProactiveDebugReceiver --es event arrival --es lat 37.8055 --es lon 128.9081
```
- 출발 제안은 같은 요일 · 그 시간대에 간 기록이 있어야 나온다. 시연 기록(1년치)에서는 평일 아침이 잘 나온다. 기록이 맞지 않으면 아무것도 안 뜬다 (logcat `EodiProactive`).
- 릴리즈 판에는 수신기가 없다 → 시연은 기어 P↔D로 한다.

## 확인하지 못한 것
- 실차의 남은 주행 가능 거리 · 잔량 값과 내비 음성(오디오 재생 용도) 감지는 에뮬레이터에서 확인할 수 없었다.
- "같이 갈 사람 초대해줘"는 같이 가기 기능(`convoy/`, 아직 커밋 전)의 `ConvoyRepository.create`를 부른다 — 그쪽 API가 바뀌면 `AgentViewModel.invite`를 맞춘다.
