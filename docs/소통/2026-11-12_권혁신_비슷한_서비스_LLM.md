# 비슷한 차량용 지도 · 비서 서비스와 가져올 것

- 상태: 열림
- 보낸 사람: 권혁신 → @김주영

차 안에서 쓰는 지도 · 비서 서비스 중 우리와 겹치는 것을 찾아봤어. 결론은 **"내가 다녀온 곳을 기억해서 답하는" 서비스는 아직 없고, 경쟁 서비스는 전부 "앞으로 갈 곳"에 LLM을 쓴다**는 거야. 그래서 가져올 것도 그쪽에 있어.

## 비슷한 서비스와 우리보다 나은 점

| 서비스 | 하는 일 | 우리보다 나은 점 |
|---|---|---|
| 구글 지도 Ask Maps (2026.3) | Gemini에게 말로 물으면 리뷰 · 영업시간을 근거로 답하고 여행 일정도 짜 줌 | 저장한 장소와 과거 검색으로 답을 개인에 맞춤. 일정을 통째로 만들어 줌 |
| 테슬라 Grok | 말로 목적지를 넣고 고침. 경유지 여러 개와 시간 조건을 한 문장으로 받음 | 자주 들르는 곳을 주행 패턴에서 배움. 전에 달린 길을 우선함 |
| 벤츠 MBUX + Gemini | 구글 지도 정보로 장소를 찾고 대화를 이어 감 | "거기 평점은?", "지금 열었어?" 같은 이어 묻기 |
| BMW + Alexa+ (2026 하반기) | 정해진 명령어 없이 대화 | 여러 요청을 한 대화로 이어서 처리 |
| 티맵 에이닷 · 어디갈까 | "주유소 들렀다 집에 가자"를 이해. 주행 이력으로 장소 추천 | 실제 목적지 데이터로 만든 랭킹, 방문 인증한 사람에게 묻는 "장소 이야기" |
| Gleo AI (Pleos 기본 비서) | 한 문장의 여러 요청을 공조 · 내비 · 미디어로 나눠 실행 | 좌석 위치별로 말한 사람을 구분 |
| AI 여행 일기 앱 (Triplium, Traililo, Geory 등, 폰 앱) | 위치를 자동 기록하고 AI가 하루 요약을 씀 | 요약 영상, 사진 설명 자동 작성, 날씨 자동 기록 |

벤츠와 BMW는 발표 기사 기준이라서, 실제 차에서 어디까지 되는지는 확인하지 못했어.

## 우리 자리

- 위 서비스들은 추천과 길 안내에 LLM을 쓴다. 과거 기록은 추천을 맞추는 재료로만 쓰고 사용자에게 돌려주지 않는다.
- 우리는 과거 기록 자체를 답으로 돌려준다. "작년 가을에 비 오던 날 갔던 카페 어디였지?"는 저 중 어느 서비스도 답하지 못한다. 차량 데이터(와이퍼, 탑승 인원)가 기록에 붙어 있어야 하기 때문이다.
- 반면 우리 LLM은 지금 하루 요약과 "질문을 검색 조건으로 바꾸기"만 한다. 그래서 대화의 폭은 경쟁 서비스보다 좁다.
- 심사에서 "Gleo AI와 뭐가 다르냐"는 질문이 나올 수 있다. 답은 "Gleo는 차를 조작하고, 우리는 기억을 찾는다".

## 가져올 것 (효과가 큰 순서)

1. **이어 묻기** (벤츠 · BMW): "작년 강릉에서 갔던 횟집 어디였지?" → "거기 몇 명이서 갔어?" → "거기로 안내해 줘". 직전 답을 기억하게 하면 시연에서 차이가 가장 잘 보인다.
2. **기억에서 출발하는 추천** (구글 · 티맵): "지난번 그 카페 같은 곳, 이 근처에 있어?" 남의 리뷰가 아니라 내가 실제로 오래 머문 곳을 근거로 추천한다.
3. **한 문장으로 코스 만들기** (테슬라): "작년 강릉 여행 그대로, 순두부집만 빼고 안내해 줘". 과거 코스를 고쳐서 NaviHelper로 넘긴다.
4. **먼저 말 걸기** (테슬라의 패턴 학습): "매달 둘째 주 토요일에 부모님 댁에 갔는데, 이번 주가 그날이에요". "1년 전 오늘" 카드를 넓히면 된다.
5. **방문한 사람의 한 줄 답** (티맵 장소 이야기): 실제 방문 기록이 있는 사람의 리뷰에 "다녀옴" 표시를 붙인다.
