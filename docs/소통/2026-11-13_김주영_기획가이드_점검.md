## 이번에 고친 것

1. 주행 화면 "기록 중" 점 깜빡임 멈춤 (반복 애니메이션 최소화)
2. Android TTS 음성 앞 150ms 선행 묵음 (차 대체 경로 · 폰)
3. 오프라인 표시 (첫 화면 머리 · 주행 화면)
4. 로그 개인정보 줄이기 (TTS 문장 · 검색어)

## 결정 · 문의가 필요한 것

- **landscape(창 2개) 확장 화면**: 지금은 portrait 고정 기본. 가이드는 "각각 설계"를 권장. 기획서에 "portrait 기본 + 창 크기 반응형"으로 적을지, landscape 화면(지도 + 하루 목록 나란히)을 만들지 정해야 함
- **앱 카테고리**: 기획서 · 앱마켓 등록용으로 Lifestyle로 할지
- **Pleos TTS 선행 묵음**: SDK에 묵음 옵션이 없음 → Pleos 기술 지원에 문의
- **주행 중 CPU 5% 미만**: 시연 경로 재생 중 `top`으로 실측해서 기획서에 숫자 넣기
- **익명화 · 데이터 활용 정책**: 기획서 개인정보 항목에 문장으로 넣기
