# UX 리뷰: 처음 쓰는 운전자 입장에서 에뮬레이터 직접 조작

- 상태: 열림
- 받는 사람: @모두
- 작성: 김주영 요청으로 AI가 차량 UX 리서처 관점에서 리뷰 (2026-11-11)
- 방법: Pleos 에뮬레이터(emulator-5554, 2560x1440, 밀도 160이라 1px = 1dp)에서 앱을 직접 눌러 보며 화면 55장 캡처. 기어 P 고정이라 **주행 중 화면은 확인하지 못함**.
- 기준: `CLAUDE.md` 사용자 편의 원칙(주행 중 음성, 큰 카드, 개인정보), Pleos 디자인 가이드 `Introduction/intro.md`(대비 4.5:1 이상, 한 문단 3줄 이하, 보조 글자 3mm 이상, 아이콘에 글자 같이), `foundations/typography.md`(글자 높이 18px 이상). 가이드에는 터치 크기 숫자가 없어서 Android Automotive 권장 최소 76dp를 참고 기준으로 썼다.
- 데이터를 바꾸는 확정 동작(게시·삭제·저장·하트·안내 확정·출장 아님)은 누르지 않았다. **예외: 하루 상세의 공유(⤴) 아이콘을 3번 눌렀는데**, 코드상 연결된 폰으로 카드를 보내는 버튼이었다(아래 1번). 폰이 연결돼 있었다면 카드가 3장 갔을 수 있다.

## 문제 목록 (심각도 높은 순)

### 1. 공유 버튼을 눌러도 아무 일도 안 일어난다 — 높음
- **위치:** 내 기록 → 하루 상세 오른쪽 위 공유 아이콘(2340,267)
- **사용자:** "눌렀는데 반응이 없네? 고장인가?" 하고 몇 번 더 누른다.
- **근거:** 3번 눌렀지만 화면 변화 없음(눌림 표시만 잠깐). 코드(`ui/share/CarHandoff.kt`)는 폰으로 카드를 보내고 결과를 `Toast`로 알리는데, 로그에 `ToastUI: Attempt to hide non-current toast from package app.eodiyeotji` — 이 AAOS 화면에서는 토스트가 보이지 않는다. 아이콘만 있고 글자가 없어 무엇을 하는 버튼인지도 모름(가이드: 아이콘에 글자 같이).
- **고칠 방향:** 토스트 대신 앱 안 스낵바/작은 확인 카드("폰으로 보냈어요 · 폰 알림을 확인하세요", 실패 시 "다시 보내기")로 바꾼다. 보내기 전 무엇이 갈지 한 장 미리보기(가려지는 집·회사 구간 포함)를 보여 주고 "보내기"로 확정. 버튼에 "폰으로 보내기" 글자를 붙인다. 중복 전송을 막게 보내는 중엔 버튼을 잠근다.
- **시연 영향:** 있음. 차→폰 공유는 시연 흐름의 일부인데 심사위원 눈에는 "안 되는 버튼".

### 2. 못 찾은 질문에 빨간 "AI 연결이 잠깐 끊겨" 오류가 뜬다 — 높음
- **위치:** 어디였지? 물어보기 → 음성 "작년 겨울에 스키 타러 갔던 데 어디였지"
- **사용자:** "인터넷이 끊겼나? 앱이 고장 났나?"
- **근거:** 약 7초 "기억을 찾는 중…" 뒤 빨간 글씨로 "AI 연결이 잠깐 끊겨 기기 안 기록만 찾아봤는데, 못 찾았어요. 다시 물어봐 주세요." + "다시 묻기" 버튼(같은 질문을 다시 보냄). 바로 이어 물은 "바다" 질문은 정상 응답 → 실제 연결 문제였는지, 결과 없음이 오류처럼 보이는지 구분이 안 된다. 앞 대화(감자탕 후보)는 통째로 사라졌다.
- **고칠 방향:** "기록이 없음"과 "연결 문제"를 다른 문구·색으로 나눈다. 없음은 평범한 색으로 "스키장 간 기록은 없어요. 작년 겨울에 다녀온 곳은 ○○·○○예요" + 대신 볼 후보 칩 2~3개. 연결 문제는 회색 안내 한 줄로 낮추고 기기 안 결과를 먼저 보여 준다. 음성으로도 한 문장 답한다(주행 중엔 화면을 못 봄). 대기 7초는 3초쯤에서 기기 안 결과를 먼저 띄운다.
- **시연 영향:** 큼. 심사위원이 즉석 질문을 던지면 바로 이 화면이 나온다.

### 3. 같은 숫자가 화면마다 다르다 — 높음
- **위치:** 기억 지도 · 올해 결산 · 하루 상세 · 그날로 돌아가기 마지막 화면 · 출장 관리 · 월 요약
- **사용자:** "어느 게 맞는 거야?" → 기록 앱의 신뢰가 무너짐.
- **근거(캡처):**
  - 기억 지도 "1년 동안 8,312km · 309일 · 814번의 길" vs 올해 결산 "7,216km · 264일 달린 날". 기간(최근 12개월 vs 2026년)이 화면에 안 적혀 있다.
  - 11월 4일: 하루 상세 "머문 곳 5곳 · 98.9km" vs 회상 마지막 "들른 곳 4곳 · 운전 1시간 21분" vs 출장 관리 "계기판 89.8km · 운전 59분", 위 요약칸 "89km".
  - 11월 요약: 칸에는 "0번 나들이 · 2번 여행", 바로 밑 문장은 "나들이 · 여행 1번 더".
  - 하루 상세 통계 이름이 날마다 다름: "8% 배터리·충"(잘림) vs "19% 쓴 배터리".
- **고칠 방향:** 기억 지도 제목을 "최근 1년(2025.11~2026.11)"처럼 기간을 박고, 결산은 "2026년 1월~오늘". 머문 곳/들른 곳은 같은 기준(집·회사 포함 여부)으로 Rust 한 함수에서 계산해 모든 화면이 같이 쓴다. 계기판 거리와 GPS 거리가 다르면 "계기판 기준"을 숫자 옆에 적는다.
- **시연 영향:** 있음. 기억 지도 → 결산을 연달아 보여 주면 바로 드러난다.

### 4. 시연용 기록 데이터가 첫 화면에서 어색하다 — 높음
- **위치:** 홈(내 기록) 날짜 목록 맨 위 3개, 월 요약 "이달의 하루"
- **사용자:** "단풍 구경인데 2분? 1분짜리 주행이 6번?"
- **근거:** 11월 7일 "가을 경포해변 단풍 구경" = 주행 6회 · 4.5km · 2분 · 머문 곳 0곳, 타임라인에 "호연재 → 경포해변 747m · 1분 미만"이 3번 반복(돌아오는 길 없음), 지도엔 750m 선 하나. 11월 8일 "경포해변 들름" 747m · 1분 미만인데 검색에선 "여행". 11월 10일 "강릉 여행" 2.7km · 7분이 11월 "이달의 하루"(같은 달 98.9km 날보다 위). 첫 이동 "07:24–07:24, 978m · 1분 미만".
- **고칠 방향:** 시연 시드에서 11/7·11/8을 실제처럼 다시 만든다(왕복·머문 곳 포함). Rust 쪽에서 500m·1분 미만 이동은 묶거나 숨기고, 같은 구간 반복은 "경포해변 주변 3번 오감"으로 합친다. "이달의 하루" 선정에 거리·머문 시간 가중치를 준다. 제목 생성은 2km·10분 미만이면 "여행/구경" 같은 큰 단어를 피한다.
- **시연 영향:** 큼. 앱을 켜자마자 보이는 화면.

### 5. 그날로 돌아가기: 사진이 지도를 덮어 글자·경로가 안 보인다 — 높음
- **위치:** 하루 상세 → 그날로 돌아가기 (11월 4일로 확인)
- **사용자:** "이게 지도야 사진이야? 글씨가 안 읽혀."
- **근거:** 머문 곳 사진(커다란 로고가 찍힌 음료 컵)을 화면 전체에 깔고 그 위에 지도·경로·지명·자막을 겹친다. 08:18 장면은 사진이 거의 불투명해 지도가 안 보이고, 14:06 장면은 컵 로고 "느린마을"과 지명·자막이 겹친다. 첫 장면 제목도 어두운 바탕에 회색 글자(대비 4.5:1 미만으로 보임). 회사 건물 장면에 음료 사진이 나와 맥락도 어긋난다.
- **고칠 방향:** 사진은 왼쪽 아래 카드(전체 폭 30% 이하)로 띄우고 지도는 그대로 보이게 한다. 자막 아래에 어두운 그라데이션(스크림)을 깔고 흰 글자 4.5:1 이상. 장소 종류가 건물/회사면 사진 대신 지도만. 끝 화면 "그 코스로 안내"는 출퇴근 날엔 숨긴다.
- **시연 영향:** 큼. 3D 회상은 시연의 핵심 장면.

### 6. 에이전트: 후보 비교가 의미 없고, 대화가 덮어써진다 — 높음
- **위치:** 어디였지? 물어보기
- **사용자:** "1번, 2번이 같은 가게잖아?" / "아까 답이 어디 갔지?"
- **근거:**
  - "예전에 갔던 감자탕집" → 후보 1·2 모두 "태조감자국"(10/11, 10/18). 견줘 볼 게 없다.
  - "옛날에 놀러 갔던 바다" → 1번이 4개월 전 을왕리, README 대표 장면인 1년 전 경포해변은 3번이고 카드가 화면 오른쪽에서 잘림(스크롤 단서 없음).
  - 후보 카드를 누르면 앞의 답 말풍선이 사라지고 새 답으로 바뀐다(대화 기록이 안 쌓임).
  - 홈 검색칸에 "경포"를 쓴 채 "어디였지? 물어보기"를 누르면 빈 입력창으로 열린다(글자가 안 넘어감).
  - 을왕리 후보 지도의 "1 을왕리해수욕장" 말풍선과 아래 사진 번호(1=조개구이, 2=해변)가 서로 다르다.
  - 에이전트 화면에는 왼쪽 메뉴가 없어 닫기(X)로만 나갈 수 있다.
- **고칠 방향:** 같은 장소는 한 후보로 합치고 "2번 다녀옴 · 10/11, 10/18"로 보여 준다. "옛날/예전/작년" 같은 말은 오래된 기록에 가중치. 후보는 3개 이하로 한 줄에 다 보이게(잘리면 "옆으로 넘기기" 표시). 대화는 아래로 쌓이게 하고 후보 선택은 "2번 볼게요" 사용자 말풍선으로 남긴다. 검색칸 글자를 물어보기로 넘긴다. 지도 번호와 사진 번호를 같은 순서로.
- **시연 영향:** 큼. "흐릿한 기억으로 찾기 → 후보 비교 → 안내"가 공모전 핵심 시나리오.

### 7. 홈 첫 화면: 무엇을 눌러야 할지 흩어져 있다 — 중간
- **위치:** 내 기록 홈
- **사용자:** "검색, 마이크, 물어보기… 뭐가 달라?"
- **근거:** 위쪽에 검색칸 + 마이크 + "어디였지? 물어보기" 3개 진입점, 그 아래 버튼 4개(11월 요약·올해 결산·기억 지도·출장 관리) + 검은 배너 "1년 동안 달린 길을 밤하늘에서 보기"(= 기억 지도와 같은 기능 두 번). 4개 버튼 모두 AI 반짝이 아이콘(출장 관리까지), 테두리가 노랑 2개·회색 2개인데 의미 없음. "● 시동 걸면 자동 기록"은 상태 표시인데 버튼처럼 생겼다. 버튼과 배너가 목록과 같이 스크롤돼 내리면 사라진다. 왼쪽 열에 날짜 카드는 3.5장만 보인다.
- **고칠 방향:** 진입점은 "말로 찾기"(마이크가 달린 큰 칸) 하나로 합치고 손 검색은 그 칸에서. 배너는 지우고 기억 지도 버튼만 남긴다. 반짝이는 AI가 실제로 일하는 곳(요약·물어보기)에만. 버튼 4개는 목록 위에 고정하거나 작은 한 줄 탭으로. 자동 기록 표시는 점+글자만(테두리 없이).
- **시연 영향:** 있음(첫인상).

### 8. 하루 상세: 날마다 버튼이 바뀌고 제목·숫자가 잘린다 — 중간
- **위치:** 하루 상세 머리
- **근거:** 11/10 "그날로 돌아가기 · 올리기 · 공유 · …", 11/7 "올리기 · 공유 · …"(돌아가기 없음), 11/4 "그날로 돌아가기 · 공유 · …"(올리기 없음). 이유 안내 없음. 11/4 제목 "출퇴근 · 현대자동차 남양연구소 · 스…"·통계 "1시간 …"·목록 "1시간 2…" 잘림. 해시태그 9개 한 줄(#강릉 #경포해변 #바다 #해변 #해수욕장 …).
- **고칠 방향:** 버튼 자리는 고정하고, 못 쓰는 날엔 흐리게 + 이유("출퇴근 기록은 올릴 수 없어요")를 누르면 보여 준다. 제목은 두 줄 허용 또는 AI 제목을 20자 이내로. 시간은 "1시간 21분"이 들어가게 칸 폭을 정한다. 태그는 3개까지.
- **시연 영향:** 있음.

### 9. 날짜를 바꿔도 타임라인이 중간부터 보인다 — 중간
- **위치:** 하루 상세 타임라인
- **근거:** 11/7에서 타임라인을 내린 뒤 11/4를 누르니 11/4 타임라인이 "–10:56 / 44.0km"부터 시작(첫 출발 08:08이 위로 숨음).
- **고칠 방향:** 날짜가 바뀌면 타임라인 스크롤을 맨 위로(LazyColumn 상태를 날짜 key로).
- **시연 영향:** 있음(그날의 시작이 안 보임).

### 10. 같은 일을 하는 버튼 이름이 제각각이다 — 중간
- **근거:** 회상: "그날로 돌아가기"(하루 상세) / "그날 보기"(출장 관리). 3D: "3D로 미리 달리기"(코스 카드) / "미리보기 비행"(코스 상세) / "비행 멈추기". 안내: "이 코스로 안내" / "그 코스로 안내" / "여기로 안내" / "안내" / "1번으로 안내" / "여기만 가기". 올리기: "내 기록에서 올리기" / "여행 코스 올리기" / "글 쓰기" / "올리기".
- **고칠 방향:** 용어표를 하나 만든다. 예: 회상=「그날 다시 보기」, 3D=「3D로 미리 보기」, 안내=「이 코스로 안내」/「여기로 안내」 두 가지만, 올리기=「코스 올리기」/「글 쓰기」.
- **시연 영향:** 낮음~중간(설명할 때 헷갈림).

### 11. 커뮤니티 4탭 구분이 안 된다 — 중간
- **위치:** 커뮤니티
- **사용자:** "드라이브 코스랑 여행 리뷰가 뭐가 달라?"
- **근거:** 여행 리뷰 카드도 "여행 코스 · 4곳" 배지를 단 코스다. 지역 리포트에는 "제휴 제안 · 첫 제휴 대상 · 지역 홍보 문구"처럼 지자체·가게 주인용(B2B) 내용이 운전자에게 그대로 나온다. 게시판 카드 오른쪽 약 320px가 비어 위 "글 쓰기" 버튼과 줄이 안 맞는다. 검색 칸 안내문이 여행 리뷰·지역 리포트에서 같다("리뷰 · 장소 찾기").
- **고칠 방향:** 탭을 「코스」(드라이브+여행, 필터로 "드라이브만/들른 곳 있는 여행")와 「게시판」 2~3개로 줄인다. 지역 리포트의 제휴 제안 블록은 운전자 화면에서 빼고 "이 지역 인기 코스·장소"만 남긴다(B2B 화면은 따로 시연). 게시판 카드 폭을 화면에 맞춘다.
- **시연 영향:** 있음(심사위원이 탭을 하나씩 눌러 봄).

### 12. 내 장소: 첫 탭이 빈 화면이고 배지 "1"의 뜻을 모른다 — 중간
- **위치:** 왼쪽 레일 내 장소(배지 1)
- **근거:** 들어가면 기본 탭 "저장한 곳"이 "아직 저장한 곳이 없어요". 배지 1은 쿠폰함 쿠폰으로 보이지만 들어가서도 안 보인다. 저장은 타임라인 "…" 메뉴 안에만 있어 찾기 어렵다. "자주 가는 곳"은 카드마다 큰 파란 "여기로 안내"가 8개(주 버튼이 경쟁).
- **고칠 방향:** 시연 시드에 저장한 곳 3~4개. 저장한 곳이 비면 "자주 가는 곳"을 먼저 연다. 배지는 쿠폰함 탭에도 같은 숫자를 단다. 장소 사진/카드에 하트를 바로 노출. 자주 가는 곳의 안내는 보조 버튼(외곽선)으로 낮춘다.
- **시연 영향:** 있음(빈 화면).

### 13. 코스 상세·미리보기 비행: 경로 선이 안 보인다 — 중간
- **위치:** 커뮤니티 → 드라이브 코스 → 7번 국도 동해안 드라이브
- **근거:** 경로가 연분홍·흰색 얇은 선이라 지형 지도 위에서 거의 묻힌다(정지·비행 둘 다). 비행 중 진행 정도, 지금 어디쯤인지 표시, "가는 길에 보이는 풍경"(경포호·주문진항…)을 지날 때 강조가 없다.
- **고칠 방향:** 경로를 진한 파랑/주황 6px + 흰 테두리로. 비행 중 아래에 진행 막대와 "지금: 주문진항" 자막, 풍경 칩을 차례로 강조.
- **시연 영향:** 있음(3D 미리보기는 볼거리 장면).

### 14. 기억 지도: 시작이 비어 있고 조작이 없다 — 중간
- **근거:** 들어가면 약 4초간 어두운 지도만(경로 없음), 날짜 글자 "2025년 11"(월 잘림). 재생 약 20초 동안 멈춤·건너뛰기 없음, 경로를 눌러도 반응 없음, 해안선·지명이 남색 바탕에 남색이라 저대비. 끝나야 "다시 보기"만 나온다.
- **고칠 방향:** 첫 프레임부터 오래된 경로가 그려지게. 날짜 칸 폭 고정. 오른쪽 위 멈춤/건너뛰기. 경로 탭 시 그날 카드. 바탕 대비 조금 올리기.
- **시연 영향:** 있음(빈 화면 4초는 시연에서 길다).

### 15. 검색 결과: 개발자 숫자 노출, 카드가 너무 커서 결과가 안 보인다 — 중간
- **위치:** 검색칸 "경포"
- **근거:** "10건 · 3.8ms"(다시 보면 "0.0ms") — 속도 수치가 사용자에게 노출. 장소 카드 1장이 높이 약 500px라 10건 중 2~3건만 보이고 "날짜 · 기록 4"는 스크롤해야 나온다. 같은 해변 사진이 여러 결과에 반복. 하늘 사진 위 흰 글자(경포호 주소) 대비 부족. 필터 칩 10개가 한 줄을 꽉 채운다.
- **고칠 방향:** ms 표시는 디버그 빌드에서만. 결과는 한 줄 목록(사진 썸네일 96px + 이름 + 마지막 방문)으로 바꾸고 장소/날짜를 탭으로 나눈다. 사진 위 글자엔 스크림. 칩은 기간 4개만 기본, 나머지는 "더보기".
- **시연 영향:** 중간(ms 숫자는 심사위원이 "이게 뭐냐" 물을 수 있음, 일부러 보여 줄 거면 "기기 안에서 0.004초"처럼 의도를 표시).

### 16. 올해 결산 그래프·문구 — 낮음~중간
- **근거:** 달마다 막대에 값·단위가 없고 연파랑 막대가 흰 바탕에서 흐림. "가장 긴 여행: 해운대 바다 보고 호텔 머무는 하루"인데 옆에 "3일". 계절 카드 "나들이 · 여행 6일"(위 칸은 "번", 여기는 "일"). 다음 달/다음 해 화살표가 눌러도 아무 일 없는데 똑같이 활성처럼 보임.
- **고칠 방향:** 막대 위 km 숫자, 최고 달만 진한 색 유지하되 나머지도 대비 3:1 이상. AI 제목에 "하루" 대신 기간 반영. 단위 통일. 끝 화살표는 흐리게.
- **시연 영향:** 낮음.

### 17. 코스 올리기 창 — 중간
- **위치:** 커뮤니티 → 내 기록에서 올리기
- **근거:** 주행 목록이 글자만(지도 썸네일 없음)이고 출퇴근 길(남양연구소 가는 길)이 맨 위. 고른 뒤 창에 지도 미리보기도, 집·회사 근처가 가려지는 모습도 없다. 소개를 "2~4문장" 직접 입력해야 하는데 받아쓰기·AI 초안 버튼이 없다(AI 앱인데 글은 사람이). "올리기"가 회색인데 왜 못 누르는지 안내 없음. 창 닫기가 X가 아닌 "<"(뒤로)라 처음엔 헷갈린다.
- **고칠 방향:** 목록은 드라이브·여행 위주로 정렬하고 썸네일. 창 위에 지도 미리보기 + 가린 구간 회색 처리 + "집 근처 1.2km는 가렸어요". AI가 만든 소개 초안을 미리 채우고 고치게. 비활성 이유를 버튼 아래 한 줄로.
- **시연 영향:** 있음("집 자동 가림"이 README 시연 포인트인데 화면에 안 보임).

### 18. 독(Dock)에 같은 아이콘이 2개 — 중간
- **근거:** 에뮬레이터 아래 독에 똑같은 파란 아이콘 2개(차 판 `app.eodiyeotji`, 폰 판 `app.eodiyeotji.phone` 둘 다 설치).
- **고칠 방향:** 시연 에뮬레이터에선 폰 판을 지우거나, 폰 판 아이콘·이름을 다르게("어디였지 폰").
- **시연 영향:** 있음(심사위원·발표자가 잘못 누를 위험).

### 19. 작은 글씨·작은 터치 대상 — 중간
- **근거(px = dp):** 왼쪽 레일 글자 약 18px, 지도 출처 글자 약 14px, 날짜 목록 "날짜별 기록" 머리 약 18px, 출장 관리 설명문 약 20px 두 줄. 타임라인 "…" 버튼은 점 아이콘 약 40px(누르는 칸도 작아 보임), 정렬 칩(인기순·최신순) 높이 약 60px, 회상 끝 "닫기" 약 90×75, 하루 상세 공유·… 원형 약 75px. 가이드의 "보조 글자 3mm 이상"을 차량 화면 거리에서 맞추려면 24px 안팎이 안전하고, 터치는 76dp 이상을 권장.
- **고칠 방향:** 보조 글자 최소 22~24px, 터치 칸 최소 76×76(아이콘이 작아도 누르는 영역을 키움), "…"는 글자 버튼("더보기")으로.
- **시연 영향:** 낮음(정차 시연), 실제 차량 심사 기준엔 영향.

### 20. 집 주소 이름이 여러 화면에 그대로 — 낮음
- **근거:** 에이전트 지도, 내 장소에 "응봉동 현대아파트 · 출발·도착"이 집 아이콘과 함께 나온다. 본인 차라 문제는 아니지만, 시연 녹화·스크린샷이 공유되면 "개인정보 기본 비공개" 앱의 메시지와 어긋난다.
- **고칠 방향:** 화면에는 "집"·"회사"로 표시하고 이름은 내 장소 > 집·회사에서만.
- **시연 영향:** 낮음.

### 21. 출장 관리 — 낮음
- **근거:** 화면 60%가 빈 공간. 출장의 실제 목적(경비 청구)용 내보내기·폰으로 보내기가 없다. "그날 보기"는 다른 화면의 "그날로 돌아가기"와 이름이 다르다. 반짝이(AI) 아이콘이 붙어 있지만 AI 기능이 아님.
- **고칠 방향:** 월 단위 "폰으로 보내기(엑셀/PDF)" 추가, 반짝이 제거, 이름 통일.
- **시연 영향:** 낮음.

## 당장 고치면 시연 인상이 가장 좋아질 5개

1. **공유 버튼 결과를 화면에 보이게 (1번).** 토스트 → 앱 안 확인 카드. 반나절이면 되고, "안 되는 버튼" 인상을 없앤다.
2. **에이전트 "못 찾음" 문구와 후보 중복 정리 (2·6번).** 빨간 연결 오류 대신 "없어요 + 대신 이 곳들", 같은 가게는 한 후보로, "옛날"이면 오래된 기록 우선, 대화는 쌓이게. 시연 핵심 시나리오.
3. **시연 기록 데이터 정리 (4번).** 11/7·11/8·11/10을 실제 같은 하루로 다시 만들고 1분 미만 이동은 묶기. 첫 화면 인상이 바로 바뀐다.
4. **숫자 통일 + 기간 표시 (3번).** 기억 지도 "최근 1년" vs 결산 "2026년" 라벨, 머문 곳 수·거리 한 곳에서 계산. 연달아 보여 줘도 안 틀리게.
5. **그날로 돌아가기 화면의 사진 겹침 정리 (5번)** + 하루 상세 버튼 자리 고정(8번). 3D 회상 장면의 글자와 경로가 또렷해진다.
