# 공공데이터 원본

| 파일 | 데이터 | 제공 | 기준일 | 행 |
|---|---|---|---|---|
| `전국휴게소정보표준데이터.csv` | [전국휴게소정보표준데이터](https://www.data.go.kr/data/15025446/standard.do) | 한국도로공사 | 2026-09-17 | 215 |
| `전국졸음쉼터표준데이터.csv` | [전국졸음쉼터표준데이터](https://www.data.go.kr/data/15028203/standard.do) | 한국도로공사 | 2026-02-25 | 253 |

- 출처: 공공데이터포털(data.go.kr), 2026-11-13 내려받음. 인코딩 CP949 (받은 그대로, 고치지 않음).
- 이용허락: 공공데이터포털 표준데이터로, 데이터 페이지의 "이용허락범위 안내"(공공데이터포털 이용정책) 기준
  공공데이터법에 따라 영리 · 비영리 구분 없이 자유롭게 이용할 수 있다. 출처를 밝힌다 → 앱 카드에 "출처: 공공데이터포털(한국도로공사 등)".
  (페이지에 공공누리 유형 표시가 따로 보이지 않았다. 바뀌면 이 메모와 README 데이터 출처 표를 고친다.)
- 앱에 들어가는 것: `core-rs/src/roadside_places.json` (UTF-8). 다시 만들기 (저장소 루트):

```bash
python -I scripts/data/build_roadside.py data/public/전국휴게소정보표준데이터.csv data/public/전국졸음쉼터표준데이터.csv
```

변환: 좌표가 우리나라 범위(위도 33–38.7, 경도 124.5–131) 밖이거나 없으면 뺀다, 같은 이름 · 100m 안 중복은 하나로.
휴게소 이름 "기흥(부산)" → "기흥휴게소 부산방향", 졸음쉼터 "서울기점 + 부산종점" → "○○졸음쉼터 부산방향".
화물차휴게소는 목록에 남기되 찾기(Rust `roadside::bundled`)에서 뺀다.
