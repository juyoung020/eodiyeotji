# 아이디어 확장: 드라이브 기억 + 코스 공유

> 가칭 후보: **길기억**, **드라이브로그(DriveLog)**, **코스북**, **오늘의 길**
> 근거 문서: `docs/31_API_한눈에보기.md`, `docs/40_평가기준_정리.md`

## 한 문장
차가 알아서 모든 이동을 기록하고 AI가 "그날"을 이야기로 요약해 두면, 말 한마디로 그때의 길을 다시 찾고, 그 기억을 다른 사람이 따라갈 수 있는 코스로 나눌 수 있다.

## 3단 구조

```
① 기록 (자동)        ② 기억 (AI 요약·검색·회상)        ③ 공유 (코스 커뮤니티)
차가 이동을 기록  →   "그날"을 이야기로 정리       →   리뷰로 올리고 좋아요를 받음
                      음성으로 찾고, 지나가면 회상       → 인기 코스의 맛집·카페도 노출
```

---

## ① 기록: 차라서 모을 수 있는 데이터 (차량특화성 핵심)

핸드폰 타임라인 앱과 다른 점은 **차에서만 알 수 있는 정보**로 그날을 풍부하게 남긴다는 것이다.

| 기록 항목 | 어떻게 알 수 있나 (API) | 요약에서 쓰는 방식 |
|---|---|---|
| 출발·도착·경유지, 경로 | FusedLocation 위치 구독, NaviHelper `onRouteStarted` / `onWayPointArrived` / `onDestinationArrived` | 타임라인 뼈대 |
| 머문 곳(정차 지점) | 위치가 멈춘 시간 + Door 열림(`registerDoorPosition`) | "○○ 식당에서 1시간 머묾" |
| **누구와 갔나** | Seat `CurrentSeatOccupancy` (좌석별 탑승) | "혼자 / 둘이 / 뒷좌석까지 4명" → 가족여행·데이트·출근 자동 분류 |
| 날씨 느낌 | Wiper 상태(비), HVAC 설정 온도, 외기 온도(AAOS 표준 API) | "비 오는 날 해안도로" |
| 주행 거리·시간 | Odometer 트립 거리·시간 | "왕복 312km, 5시간 운전" |
| 연비·전비 | Fuel / EvBattery 효율 | "이 코스는 전비 6.1km/kWh" (EV 운전자에게 유용) |
| 충전소·휴게소 | NaviHelper 충전소 정보, 정차 위치 | "○○휴게소에서 20분 충전" |
| 분위기 | Light 앰비언트 색, 주행 모드(DrivingMode) | 스포츠 모드 드라이브 코스 태그 |
| 내비 즐겨찾기 | NaviHelper `getBookmarkInfo` (HOME/OFFICE) | 집·회사 자동 인식 → 출퇴근 자동 분류, **공유 때 자동 가림** |

## ② 기억: AI 요약, 검색, 과거 회상

### 2-1. 하루 요약 (LLM)
하루가 끝나면 기록을 LLM에 넣어 짧게 요약하고 태그를 붙인다.
- 예: "**2026.08.14 (금) · 가족 4명 · 강릉 바다 여행** — 오전 7시 집 출발, 횡성휴게소 들러 경포해변 도착. 초당순두부에서 점심 후 안목 카페거리. 비 조금, 왕복 420km."
- 자동 태그: `#출근` `#여행` `#드라이브` `#데이트` `#가족` `#바다` `#산` `#야경` `#맛집`
- 출퇴근처럼 반복되는 날은 "평소 출근(정상)"으로 묶어서 타임라인을 깔끔하게 정리

### 2-2. 자연어·음성 검색
- 운전 중: STT로 "작년 여름에 바다 갔던 데 어디였지?" → 결과를 TTS로 읽어줌 → "거기로 안내해줘" 하면 NaviHelper로 바로 길 안내
- 정차 중: 날짜(년·월·일), 장소, 동승자, 태그로 검색
- 검색 예: "비 오는 날 갔던 카페", "엄마 모시고 갔던 식당", "충전하기 편했던 강원도 코스"

### 2-3. 과거 회상 (추억 기능)
기록이 쌓일수록 가치가 커지는 기능이다. **재방문(Retention)을 만드는 핵심**이기도 하다.

| 기능 | 동작 | 사용 API |
|---|---|---|
| **지나가면 떠오르는 기억** | 예전에 들렀던 곳 근처를 지나면 "3년 전 이 길로 가족이랑 바다 갔었어요"라고 짧게 음성 안내 | FusedLocation `addProximityAlert`(지오펜스 ENTER) + TTS |
| **N년 전 오늘** | 시동을 걸면 "1년 전 오늘은 제주 해안도로를 달렸어요" | 날짜 매칭 + TTS (정차 중 카드 표시) |
| **연말 결산** | "올해 7,800km, 23곳 여행, 가장 많이 간 곳은…" 리포트 | Odometer + 기록 집계 |
| **그날 다시 달리기** | 회상한 코스를 그대로 내비 경로로 불러오기 | NaviHelper `requestRouteWithWaypoints` |
| **함께 탄 사람 기억** | "이 사람과 간 곳" 모아보기 (좌석 탑승 + 사용자가 붙인 이름) | Seat occupancy |

## ③ 공유: 코스 커뮤니티

- 하루 기록을 **코스 리뷰**로 바꿔서 올림: 경로 + 들른 곳 + 사진/메모 + AI 요약문
- 좋아요, 저장, "따라가기" 횟수로 인기 코스 순위
- **따라가기**: 다른 사람의 코스를 누르면 내비에 경로가 바로 들어감
- 인기 코스에 들어간 식당·카페는 자연스럽게 노출됨 → 가게 홍보 효과
- 필터: 지역, 계절, 소요 시간, 동승 유형(가족/연인/혼자), **EV 충전 가능 여부**, 반려동물 동반
- EV 사용자용: NaviHelper `requestTrip`의 "도착 시 예상 배터리 %"로 **"내 차로 이 코스 가능?"** 표시

### 주의할 기술 제약
- NaviHelper 경유지는 **최대 2개**(`WaypointIndex.FIRST`/`SECOND`)
  → 들른 곳이 많은 코스는 "구간(leg)"으로 나누고, 한 구간에 도착하면 다음 구간을 자동으로 요청
- Vehicle·FusedLocation은 차종마다 지원이 다름 → `checkXxxCapabilities()` / `isSupported()`로 확인 후 기능 켜기
- **LLM SDK는 공모전 공식 SDK 5종에 없음** → 선택지:
  1. 자체 서버에서 외부 LLM API로 요약 (확실함)
  2. Pleos LLM SDK 사용 가능 여부를 운영사무국에 문의
  3. 기획서에는 "Pleos LLM SDK 연동 확장 가능"으로 적고 1번으로 구현

## 안전·개인정보 설계 (심사에서 신뢰를 얻는 부분)
- **주행 중**: 음성으로만 조작하고 화면은 최소한으로 사용 (Pleos 운전자 주의 분산 가이드를 따름). 피드 보기와 리뷰 쓰기는 **정차 중에만**
- 회상 음성 안내는 짧게, 하루 횟수를 제한하고, 내비 안내 음성과 겹치지 않게 함 (오디오 포커스 가이드)
- 위치 기록은 민감 정보 → 기본은 차량·내 계정에만 저장하고, 공유는 코스 단위로 직접 선택해야 함
- 공유할 때 **집·회사 근처 구간은 자동으로 가림** (내비 즐겨찾기 HOME/OFFICE 활용)
- 동승자 정보는 공유하지 않음

## 평가 항목별로 강조할 점

| 평가 항목 | 강조 포인트 |
|---|---|
| 차량특화성 | 탑승 인원, 와이퍼(비), 연비·전비, 정차·도어 이벤트처럼 **차에서만 아는 데이터**로 기억을 남김. 회상 기능은 "그 길을 지날 때" 동작함. 따라가기는 내비와 바로 연동됨 |
| 창의성 | 이동 기록을 **기억 검색**과 **추억 회상**으로 바꾸고, 그 기억을 **공유 가능한 코스**로 만드는 흐름 |
| 기술 활용성 | SDK 5종을 모두 씀: FusedLocation(기록·지오펜스), NaviHelper(이벤트·따라가기·트립), Vehicle(탑승·와이퍼·주행·전비), STT(음성 검색), TTS(회상 안내) |
| 사업성 | 타깃: 주말 드라이브와 여행을 즐기는 운전자, 가족 단위, EV 오너. 회상과 연말 결산으로 재방문을 만들고, 인기 코스에 들어간 가게의 제휴·쿠폰으로 수익. 지자체·관광공사와 테마 코스 제휴 |

## 사업 모델 아이디어
- 지역 가게 **제휴 배지·쿠폰**: 인기 코스에 들어간 가게가 "코스 공식 맛집"으로 노출됨 (광고임을 표시)
- **지자체·관광공사 테마 코스**: "가을 단풍 드라이브 10선" 같은 공식 코스
- EV 충전 사업자 제휴: 코스 위 충전소 추천
- 프리미엄: 연말 결산 영상, 기록 무제한 보관

| 기획서에만 적기 | 가게 제휴, 지자체 코스, 연말 결산 영상 |

## 남은 질문
- 앱 이름
- 팀 구성 (대학생 부문인지)
- LLM은 무엇으로 쓸지 (외부 API vs Pleos LLM SDK 문의)
- 공유 커뮤니티 서버를 직접 만들지, Firebase 같은 서비스를 쓸지
