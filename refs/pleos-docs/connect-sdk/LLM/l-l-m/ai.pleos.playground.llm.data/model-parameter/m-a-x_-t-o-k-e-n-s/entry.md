# MAX_TOKENS

[MAX_TOKENS](https://document.pleos.ai/docs/pleos-only/connect-sdk-pleos/LLM/l-l-m/ai.pleos.playground.llm.data/model-parameter/m-a-x_-t-o-k-e-n-s/entry)

The `MAX_TOKENS` parameter defines the maximum number of tokens generated by the model.

- Expected values are integers as strings, e.g., "512"

- This defines the upper limit of tokens (words, punctuation, etc.) the model can generate in response.

- Example values: 512, 1024.
