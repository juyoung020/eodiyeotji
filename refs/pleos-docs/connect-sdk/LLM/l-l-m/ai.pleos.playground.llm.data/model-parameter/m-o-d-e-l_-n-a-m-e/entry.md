# MODEL_NAME

[MODEL_NAME](https://document.pleos.ai/docs/pleos-only/connect-sdk-pleos/LLM/l-l-m/ai.pleos.playground.llm.data/model-parameter/m-o-d-e-l_-n-a-m-e/entry)

The `MODEL_NAME` parameter specifies the name of the language model to be used.

- This value determines which pretrained model will be loaded and utilized.

- Expected values are predefined model names as strings, e.g., "chatbaker-16k," "gpt-4o-mini."

- Example values: "chatbaker-16k," "gpt-4o-mini," "gpt-4o."
