# TEMPERATURE

[TEMPERATURE](https://document.pleos.ai/docs/pleos-only/connect-sdk-pleos/LLM/l-l-m/ai.pleos.playground.llm.data/model-parameter/t-e-m-p-e-r-a-t-u-r-e/entry)

The `TEMPERATURE` parameter controls the randomness of the model's output.

- Expected values are floating point numbers as strings, e.g., "1.0," "1.3."

- A higher value makes the output more random and creative, while a lower value makes it more deterministic.

- Typical range: 0.0 to 2.0.
