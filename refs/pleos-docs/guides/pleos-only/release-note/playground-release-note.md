# Pleos Playground

## 2026년 10월 29일[​](#2026년-10월-29일 "2026년 10월 29일에 대한 직접 링크")

> **Release version:** Pleos Playground v2.7.0\
> **Release date:** 2026년 10월 29일

\

이번 업데이트에서는 Pleos Playground의 주소를 변경하고, Pleos 브랜드 사이트와의 연결 및 개발자 가이드 검색 기능을 개선했습니다.

### Improvements[​](#improvements "Improvements에 대한 직접 링크")

#### Pleos Playground 주소 변경[​](#pleos-playground-주소-변경 "Pleos Playground 주소 변경에 대한 직접 링크")

Pleos Playground의 주소가 `pleos.ai/playground`에서 `developers.pleos.ai`로 변경됩니다.

#### 메뉴 및 푸터 개선[​](#메뉴-및-푸터-개선 "메뉴 및 푸터 개선에 대한 직접 링크")

Pleos Playground의 Pleos Connect와 Pleos App Market 메뉴를 새롭게 오픈한 Pleos 브랜드 사이트로 연결하고, 페이지 하단의 푸터 구성을 개선했습니다.

#### 문서 검색 기능 개선[​](#문서-검색-기능-개선 "문서 검색 기능 개선에 대한 직접 링크")

개발자 가이드의 소제목으로도 문서를 검색할 수 있도록 검색 범위를 확대했습니다. 검색 결과에서 문서의 위치도 함께 확인할 수 있어 필요한 정보를 더 쉽게 찾을 수 있습니다.

\

## 2026년 10월 19일[​](#2026년-10월-19일 "2026년 10월 19일에 대한 직접 링크")

> **Release version:** Pleos Playground v2.6.0\
> **Release date:** 2026년 10월 19일

\

이번 업데이트에서는 Pleos Playground의 사이트 구조와 탐색 기능을 개편하고 문서 검색 기능을 추가하여 개발자 경험을 개선했습니다. 사이트와 개발자 가이드를 앱 개발 흐름에 맞춰 재구성하여 개발 단계별로 필요한 정보와 자료를 더 쉽게 찾을 수 있습니다.

### New Features[​](#new-features "New Features에 대한 직접 링크")

#### 개발자 여정 가이드[​](#개발자-여정-가이드 "개발자 여정 가이드에 대한 직접 링크")

초기 설정부터 개발 및 검증까지 Pleos 앱 개발의 전체 과정을 단계별로 확인할 수 있습니다. Pleos Playground 메뉴에서 **Discover** \> **Developer Journey**를 확인하세요.

#### 문서 검색 기능[​](#문서-검색-기능 "문서 검색 기능에 대한 직접 링크")

Pleos Playground 상단의 검색 아이콘을 통해 문서를 검색할 수 있습니다.

### Improvements[​](#improvements-1 "Improvements에 대한 직접 링크")

#### Pleos Connect 개발자 가이드[​](#pleos-connect-개발자-가이드 "Pleos Connect 개발자 가이드에 대한 직접 링크")

Pleos Playground의 개발자 여정에 맞춰 Pleos Connect 개발자 가이드를 재구성했습니다. 앱 개발 시작부터 기획·설계, 개발·연동, 테스트, 앱 등록까지 개발 과정에 따라 필요한 문서를 더 쉽게 찾을 수 있습니다.

[Pleos Connect 앱 개발 시작하기](https://document.pleos.ai/docs/pleos-only/getting-started)

개편된 구조에서 주요 가이드를 다음과 같이 확인할 수 있습니다.

- Pleos Connect Virtual Console 가이드
  - Pleos Connect Virtual Console의 설정 및 사용 방법을 안내합니다.
  - [Pleos Connect Virtual Console 셋업 가이드](https://document.pleos.ai/docs/connect/guide/getting-started/application-development/use-vehicle-emulator)
- 폼 팩터 테스트 가이드
  - Pleos Connect Emulator에서 다양한 디스플레이 해상도와 방향에 따라 앱 화면이 정상적으로 표시되는지 테스트하는 방법을 안내합니다.
  - [폼 팩터 테스트 가이드](https://document.pleos.ai/docs/pleos-only/app-test-guide/form-factor-test-guide)
- Vehicle SDK Sample App 사용 가이드
  - 차량 기능의 지원 범위 확인, 현재 상태 조회, 상태 변경 요청, 변경 알림 구독 등 Vehicle SDK의 사용 흐름을 익힐 수 있는 샘플 앱의 사용 방법을 안내합니다.
  - [Vehicle SDK Sample App 사용 가이드](https://document.pleos.ai/docs/pleos-only/tutorial/vehicle-sdk-sample-app)

### Removed Features[​](#removed-features "Removed Features에 대한 직접 링크")

#### LLM SDK[​](#llm-sdk "LLM SDK에 대한 직접 링크")

LLM SDK 제공을 종료합니다. Gleo AI와의 연동이 필요한 경우 [Gleo Interface](https://document.pleos.ai/docs/pleos-only/app-integration-guide/guide/core-concepts)를 이용할 수 있습니다.
