# Pleos Connect Emulator 정식 릴리즈

- **Release version:** Pleos Connect Emulator v2.1.0
- **Release date:** 2026년 10월 19일

## Pleos Connect Emulator[​](#pleos-connect-emulator "Pleos Connect Emulator에 대한 직접 링크")

### New Features[​](#new-features "New Features에 대한 직접 링크")

- Pleos Connect Virtual Console 제공
  - 도메인별 차량 상태/이벤트를 설정하고 앱 반응을 검증할 수 있는 테스트 환경 추가
  - [Virtual Console 사용 가이드](https://document.pleos.ai/docs/pleos-only/app-test-guide/virtual-console-guide)
- 테스트 기능 제공
  - 화면 크기/해상도/레이아웃 변화 검증을 위한 폼팩터 테스트용 에뮬레이터 기능 추가
  - [폼팩터 테스트 가이드](https://document.pleos.ai/docs/pleos-only/app-test-guide/form-factor-test-guide)

### Improvements[​](#improvements "Improvements에 대한 직접 링크")

- 에뮬레이터 탑재 SDK 버전 업데이트로 API 지원 범위 확대

SDK 변경 상세

Pleos Connect SDK 버전 및 변경 내역은 [Pleos Connect SDK 릴리즈 노트](https://document.pleos.ai/docs/pleos-only/release-note/sdk-release-note)를 참고하시기 바랍니다.

### Removed Features[​](#removed-features "Removed Features에 대한 직접 링크")

- LLM SDK 제공 종료
- CRN 제공 종료
- 블루투스 동글 연동 제공 종료
